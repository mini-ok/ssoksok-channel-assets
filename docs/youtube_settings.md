# 유튜브 채널·업로드 설정 점검 (2026-10-26)

출처: 사용자가 공유한 「해외 유튜브 전문가들만 몰래 쓰는 유튜브 설정 8가지」(흰지로의 오답노트, https://youtu.be/5QVuFhhcCrU).
이 영상은 해외 영상 두 편(Dan the creator "7 easy YouTube settings you NEED to turn on NOW", vidIQ "16 YouTube Settings EVERYONE Should CHANGE NOW")을 정리한 것이다.
이 환경에서는 유튜브가 자막·페이지 수집을 막아 영상 본문을 직접 읽지 못했고, 영상 설명(제목·타임라인·원본 링크)과 두 원본 영상의 설명으로 항목 범주(채널 레이아웃, 업로드 기본값, 재생목록, Studio 놓치기 쉬운 기능, 아동용 설정, 라이선스, 유료 홍보 표시 등)만 확인했다.
그래서 **우리 채널의 실제 설정을 API로 읽어 범주별로 점검**하고, 확실히 도움 되는 것만 반영했다.

## 이미 맞게 되어 있던 것 (변경 없음)
- 채널 국가/기본 언어: KO = KR/ko, EN = US/en
- 채널 키워드, 소개글, 배너, 프로필(프로필 사진은 수동)
- 아동용 설정: 모든 영상 `selfDeclaredMadeForKids=false` (직장인 대상 콘텐츠)
- 영상 기본 언어·오디오 언어(ko/en), 카테고리 27, 공개 상태, 퍼가기·통계 공개
- 재생목록: 시트콤 롱폼 / 주제별 시리즈 / 쇼츠 / 옛 전집, 설명란에 연결 링크
- 첫 댓글, 엔딩 카드(영상 안), 썸네일 업로드

## 이번에 반영한 것
1. **홈 화면 섹션**: 새 컨셉인 「몸속 주식회사 시트콤」 목록이 홈에 없었다 → 맨 위에 추가. 순서: 시트콤 → 쇼츠 모음 → 주제별 정주행(5개였던 시리즈를 7개 모두로) → 옛 전집. 영어도 동일(The Office Sitcom → Shorts → Binge by topic → Office Life).
2. **채널 예고편(비구독자에게 보이는 영상)**: 옛 정보형 롱폼(거북목 / 낮잠)이었다 → 카페인 시트콤 롱폼으로 교체(KO `_fPv_rmFEAM`, EN `sAmyUJWsfms`). 새 컨셉으로 처음 오는 시청자가 첫인상을 보게 한다.
3. **구독자 알림 폭주 방지**: 하루 5회 × (롱폼 + 쇼츠 2)가 모두 구독자에게 알림으로 나가면 알림 끄기·구독 취소가 늘 수 있다 → 업로드 시 숏폼은 `notifySubscribers=false`, 롱폼만 알림(`engine/pipeline/upload/upload.py`). 롱폼 알림도 줄이고 싶으면 `notify`를 하루 첫 롱폼에만 켜도록 바꿀 수 있다.

## 사용자가 Studio에서 직접 해야 하는 것 (API로 못 바꿈)
- 설정 → 업로드 기본 설정: 기본 제목 접미/설명 템플릿·언어·카테고리(우리는 업로드 때 API로 매번 지정하므로 선택 사항)
- 설정 → 채널 → 고급 설정: '아동용 아님' 기본값 확인, 광고 연결 등
- 커스터마이징 → 맞춤 영상 설정: 구독자용 추천 영상(재방문 구독자에게 보이는 영상) — 시트콤 최신 롱폼으로
- 댓글: '부적절할 수 있는 댓글 검토 보류' 설정, 영상별 댓글 정렬
- 쇼츠: '리믹스 허용'(기본 켜짐) 유지, 최종 화면 요소(롱폼), 첫 댓글 고정
- 언어 자막: 필요하면 자동 자막 검수(업로드된 자막 파일 올리기는 쿼터가 커서 보류)

## 보류/해당 없음
- 영상 제목·설명 번역(localizations): 한·영 채널이 분리돼 있어 이득이 작아 보류.
- 합성·변형 콘텐츠 표시: 현실적 사람 영상이 아니라 애니메이션이라 해당 없음(기존 지시 유지).
- 라이선스: 표준 유지.
