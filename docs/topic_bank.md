# 주제 은행 — 사람들이 클릭하고 싶은 주제 (2026-10-27, 사용자 지시)

**원칙:** 사람들이 많이 궁금해하는 주제(수명, 모발, 시력, 치매 예방, 젊은 층 암, 체중, 수면의 질, 면역, 통증)를 다루되, **비중이 큰 핵심 요인부터 원리와 행동으로** 풀고 최신 연구는 보너스로 쓴다(2026-10-27 개정).
제목은 호기심을 끌되 **과장·공포 조장·낚시 금지**: 영상이 약속을 지켜야 하고, 의학적 단정·치료 권유·"~가 낫는다/다시 좋아진다" 같은 효능 보장은 하지 않는다. 구체적 방법·수치(3-10 정보 가치 기준)와 출처(기관·논문·연도)가 있어야 한다.
**후보는 전부 '검증 전'이다.** 실행이 제작 때 원문을 WebFetch/WebSearch로 직접 확인해, 사실이 아니거나 근거가 약하면 그 주제는 건너뛰거나 확인된 범위로 좁힌다.

## 선정 기준(실행이 후보를 고를 때)
1. 근거가 강하고 비중이 큰 핵심 요인을 중심으로 다룰 수 있는가(최근 연구는 보너스; 발표 연도·기관은 출처 자막에 쓴다).
2. 항목마다 '왜(원리) → 어떻게(행동·운동)'가 나오는가(3-10). 검사 권유만 있는 항목은 3가지에 넣지 않는다.
3. 겁을 주지 않고도 '클릭하고 싶은' 질문형 제목이 가능한가.
4. 이미 올린 주제와 겹치지 않는가(채널 uploads 확인). **같은 분야(수면·식습관·카페인 등)가 최근 3편 안에 있으면 다른 분야를 고른다(사용자 지시 2026-10-28).**
5. 소재가 약을 복용하라거나 치료를 대신하는 안내로 번지지 않는가(번지면 '의료진 상담' 안내로 좁힘).
