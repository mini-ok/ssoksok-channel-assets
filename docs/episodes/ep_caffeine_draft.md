# 「카페인 컨설턴트의 청구서」 대본 초안 v2 (피드백용)

- v2 변경(사용자 피드백): **긴급상황 오프닝 → 우왕좌왕 → 곧바로 정보①(왜 늦게까지 남나) → 후반 시작 빵 터지는 절정 → 정보②(오늘의 3가지) → 엔딩 유머.** 설명이 느리던 v1(설명이 1분 뒤에 나옴)을 25초 안으로 당김.
- 오늘의 3가지(금지·한도·확인): ① 커피 마감 시간(자기 6시간 전) ② 하루 한도(FDA 400mg ≈ 커피 4~5잔) ③ 숨은 카페인 확인(차·콜라·초콜릿·에너지 음료)
- 수치(제작 때 출처 확인 후 맞는 것만, 틀리면 대사 수정): 카페인 반감기 평균 약 5시간(개인차 큼) / 잠들기 6시간 전 카페인도 수면을 줄였다는 실험(Drake 2013, 소규모) / FDA 하루 400mg 안내.
- 출연(sid): 카페인 컨설턴트 9, 뇌 팀장 5, 아데노신 8, 멜라토닌 7, 간 과장 3, 면역 경비 6, 해설 0. 대사 약 430자(공백 제외, 재측정) ≈ 50초 + 사이렌·되감기·칩·서류 눈사태 등 연출 → 약 1분 50초~2분 5초.
- 템포 곡선: 오프닝 최고 템포(소란) → 설명 구간 또렷하게 → 절정 최고조 → 3가지 빠른 연타 → 정적 1초 → 엔딩 반전.

## 개성 포인트 (이번 편에서 한 번씩 터지게)
| 캐릭터 | 개성 장치 |
|---|---|
| **카페인 컨설턴트** | 말끝 늘이는 능글 "~", 명함 휙. 절정에서 **사실은 본인도 퇴근 못 해서 쩔쩔맴**(반전). 엔딩 "저도 칼퇴하고 싶거든요~" |
| **뇌 팀장** | "자, 정리해 보면…" 매번 정리 실패. 소란 속에서 혼자 "정리!" 외치다 묻힘 |
| **아데노신** | 축 처진 목소리, 서류 탑. 소란 속에서도 느릿느릿 "서류가 안 들어가요…" → 절정에서 갑자기 빨라짐 |
| **멜라토닌** | 소심 "불 끌게요…?"를 아무도 안 들음 → 엔딩에서 "불, 끌게요!" |
| **간 과장** | 말없이 야근. "…제가 할게요." 소란 속에서 혼자 바닥 닦음 |
| **면역 경비** | "신분증 보여주세요." 모두에게(컨설턴트에게도, 콜라에게도) |

## 1막 · 긴급상황 오프닝 (0:00~0:22) 〔최고 템포, 컷 1.5초〕
[밤 11:00 · 사이렌 🚨 '비상! 잠이 안 옵니다' 자막 · 사무실 전체 우왕좌왕]
해설(0): 밤 열한 시. 몸속 주식회사에, 비상이 걸렸어요!
뇌 팀장(5) — 허둥지둥: 자, 정리해 보면… 정리가… 안 돼요!
멜라토닌(7) — 셔터 리모컨 들고, 아무도 안 들음: 저, 저기… 불 끌게요…?
면역 경비(6) — 아무나 붙잡고: 신분증 보여주세요! 신분증!
아데노신(8) — 서류 탑 옆에서 느릿느릿: 서류가… 안 들어가요…
간 과장(3) — 혼자 바닥 닦으며: …제가 할게요.
(화면 가득 우왕좌왕, 서류 날림, 사이렌. 뇌 팀장이 외침 → 전원 멈춤)
뇌 팀장(5): 범인이 누구야!

## 2막 · 정보① 딱 (0:22~0:48) 〔또렷, 짧게〕
[CCTV 되감기 · 자막 '오후 3:00'] — 되감기 연출, 화살표 빨간 동그라미
해설(0): 범인은, 오후 세 시에 들어온 커피예요.
(카페인 컨설턴트, 명함을 휙 던지며 CCTV 속에서 윙크)

**[큰 칩 ① '카페인 절반이 나가는 데 약 5시간']** (게이지 100% → 50% 애니메이션, 시계 오후 3시→8시)
해설(0): 카페인은 절반으로 줄어드는 데, 평균 다섯 시간쯤 걸려요. 사람마다 달라요.
간 과장(3) — 담담한 인터뷰 컷: 밤 열한 시에도, 아직 사 분의 일이 남아 있어요. …제가 치우고 있고요.
(전원 뇌 팀장을 쳐다본다.)
뇌 팀장(5) — 눈 돌리며: …제가 불렀죠.

## 3막 · 후반 시작 · 빵 터지는 절정 (0:48~1:15) 〔최고조 → 폭발〕
[사무실 문 앞 · 컨설턴트가 나가려는 중]
카페인 컨설턴트(9) — 갑자기 쩔쩔맴, 말끝 안 늘임: 저도 퇴근하고 싶은데~ 문이 안 열려요~!
(사실 컨설턴트도 간 과장의 '해독 게이지'가 안 줄어들어 퇴근 못 하는 것. 컨설턴트가 문 앞에서 발만 동동)
뇌 팀장(5) — 눈치 없이: 그럼 한 잔 더! 컨설턴트님 동료 불러요!
(문이 열리며 **에너지 음료·콜라·초콜릿·녹차**가 줄줄이 입장, 사원증에 전부 '카페인 소속' 도장)
면역 경비(6) — 입 벌어짐, 떨리며: ……신분증 보여주세요.
콜라 — 사원증을 쾅: 카페인 소속이요~
(컨설턴트가 머리를 감싸 쥐며 ※ 터지는 컷: 사무실이 카페인 동료로 가득)
아데노신(8) — 느린 목소리가 폭발적으로 빨라짐: 서류가 무너져요오오!
(서류 탑 붕괴, 눈사태처럼 뇌 팀장이 서류에 묻힘, 정적 0.5초, 서류 더미 속에서 손만 올라온다)
뇌 팀장(5) — 서류 속에서: …정리, 정리해 보면…

## 4막 · 정보② 오늘의 3가지 (1:15~1:40) 〔연타, 번호 칩 쾅쾅쾅〕
[사내 방송 땡 · 간 과장이 소매를 걷으며 혼자 앞에 선다]
간 과장(3) — 한숨 쉬며: …제가 할게요. 오늘의, 세 가지!
**[큰 칩 ① '커피 마감 = 자기 6시간 전']** (컨설턴트 퇴근 보드에 '오후 4시' 도장 쾅. 게이지 25%→15%)
**[큰 칩 ② '하루 한도 = 커피 4잔 안쪽']** (간 과장이 서류 더미를 순식간에 정리. 게이지 15%→8%)
**[큰 칩 ③ '숨은 카페인 = 차·콜라·초콜릿·에너지 음료']** (면역 경비가 신분증 검사, 명찰이 반짝)
해설(0): 하나, 커피는 자기 여섯 시간 전까지만. 둘, 하루 네 잔 안쪽. 셋, 차랑 콜라, 초콜릿도 카페인이에요!

## 확인받고 싶은 점
1. 설명이 25초(0:22~0:48)에 들어오는 속도가 괜찮은지.
2. 절정 개그(컨설턴트도 퇴근 못 해 쩔쩔맴 → 카페인 동료 줄줄이 입장 → 서류 눈사태)가 터질 만한지.
3. 3가지(마감 시간, 하루 한도, 숨은 카페인)와 엔딩 반전(칼퇴) 유지 여부.
