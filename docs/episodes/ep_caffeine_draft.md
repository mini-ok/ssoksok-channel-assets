# 「카페인 컨설턴트의 청구서」 대본 초안 v1 (피드백용)

- 구조(예전 롱폼+쇼츠 2 방식을 시트콤에 적용): 롱폼 = **덩이① 문제**(오후 커피가 밤까지 남는 이유) + **덩이② 해결 '오늘의 3가지'**. 쇼츠 A = 덩이①을 질문형 입말 후크로, 쇼츠 B = 덩이②를 '딱 세 가지'로.
- 오늘의 3가지(금지·한도·확인): ① 커피 마감 시간 정하기(자기 6시간 전) ② 하루 한도(FDA 400mg ≈ 커피 4~5잔) ③ 숨은 카페인 확인(차·콜라·초콜릿·에너지 드링크)
- 수치(제작 때 출처 확인 후 맞는 것만 사용, 틀리면 대사 수정): 카페인이 몸에서 절반으로 줄어드는 데 평균 약 5시간(개인차 큼, Sleep Foundation 등) / 잠들기 6시간 전 카페인도 수면을 줄였다는 실험(Drake 2013, 소규모) / FDA 하루 400mg 안내.
- 출연: 카페인 컨설턴트(9), 뇌 팀장(5), 아데노신(8), 멜라토닌(7), 간 과장(3), 면역 경비(6), 해설(0). 대사 약 420자 → 1.25배에서 약 1분 + 게이지·사내 방송·칩 연출 장면 = 약 1분 45초~2분.

## 이번 편 캐릭터 개성 포인트
| 캐릭터 | 이번 편의 역할 | 개성 장치 |
|---|---|---|
| **카페인 컨설턴트** | 계약직 외부 컨설턴트. 피로를 '잠깐' 막아주고 밤에 청구서를 보냄 | 말끝을 늘이는 "제가 잠깐 막아드리죠~", 명함을 건넴, 절대 먼저 안 나감. 반전에서 "저도 칼퇴하고 싶거든요~" |
| **아데노신** | 피로 보고서 담당. 결재함이 막혀 서류가 쌓임 | 축 처진 목소리 "보고서 또 쌓였어요…", 쌓인 서류 탑이 점점 높아짐, 마지막에 처음으로 결재 받음(감동) |
| **멜라토닌** | 야간 셔터 신입. 소심하지만 마지막에 용기 | "이제… 불 끌게요…?" 가 점점 커져 마지막엔 "불 끌게요!" 한마디 |
| **간 과장** | 카페인 분해 담당. 말없이 야근 | "…제가 할게요." + 한숨, 컨설턴트 퇴근 게이지를 혼자 닦음, 조용한 감동 |
| **면역 경비** | 신분증 검사 | "신분증 보여주세요." 를 컨설턴트에게도, 차·콜라·초콜릿에도 (숨은 카페인 확인) |
| **뇌 팀장** | 의존하는 팀장 | "자, 정리해 보면…" 정리 실패, 컨설턴트 앞에서 약해지는 표정 |

## 1막 · 발단 (약 25초) 〔느긋→보통〕
[사무실 · 자막 '오후 2:56' · 아데노신 결재함에 서류 탑]
해설(0): 오후 두 시 오십육 분. 몸속 주식회사 기획팀은, 졸음과 싸우는 중이에요.
아데노신(8) — 축 처져서: 보고서 또 쌓였어요… 팀장님, 결재해 주세요…
뇌 팀장(5) — 눈이 감기며: 자, 정리해 보면… 일단, 커피!
(사내 방송 땡: 외부 컨설턴트 입장. 카페인이 명함을 펄럭이며 등장, 반짝이 효과)
카페인 컨설턴트(9) — 느끼하게, 말끝 늘여: 제가 잠깐, 막아드리죠~ 결재함은 제가 받을게요~
(카페인이 아데노신 결재함 자리에 앉아 버리고, 서류 탑이 더 못 들어오게 막힌다.)

## 2막 · 전개 (약 25초) 〔빨라짐〕
[사무실 · 낮, 뇌 팀장 번쩍 일어남]
뇌 팀장(5) — 신남: 오! 집중돼! 자료 정리 끝! 컨설턴트님, 최고예요!
카페인 컨설턴트(9): 별말씀을~ 정산은 이따 밤에~ 해 드릴게요~
아데노신(8) — 서류 탑 옆에서 작게: …보고서는, 안 사라지고 기다리는 중인데요…
(서류 탑이 몰래 높아지는 컷. 한쪽에서 간 과장이 카페인 청구 게이지를 닦음.)
(인터뷰 · '간 과장 · 해독팀')
간 과장(3) — 담담하게: 컨설턴트님은 한번 오시면, 절반이 나가는 데 다섯 시간쯤 걸려요. …그동안 제가 치워요.

## 3막 · 해결 시도 3가지 → 절정 (약 55초) 〔긴박, 컷 2초〕
[야간 · 자막 '밤 10:50' · 게이지 100% → 50% → 25%]
해설(0): 밤 열 시 오십 분. 컨설턴트님은, 아직 퇴근을 안 하셨어요.
멜라토닌(7) — 셔터 리모컨을 들고, 소심하게: 저, 저기… 이제 불 끌게요…?
카페인 컨설턴트(9): 아직 안 갔어요~ 한 잔만 더~
뇌 팀장(5) — 당황, 말 꼬임: 정리, 정리해 보면… 잠이, 안 와요!
🚨 사내 방송: 보고서 폭주! 보고서 폭주! 아데노신 결재함 한계 초과!
아데노신(8) — 절규하듯, 느린 목소리가 갑자기 빨라짐: 서류가 무너져요오!

**[큰 칩 ① 커피 마감 시간]**
뇌 팀장(5): 해결 하나! 커피 마감 시간표! 자기 여섯 시간 전까지만 부르기!
(컨설턴트의 퇴근 시각 보드에 '오후 4시'가 쾅 도장. 게이지 25% → 15%)
**[큰 칩 ② 하루 한도]**
간 과장(3) — 한숨 쉬며 소매 걷고: 둘, 하루 한도. 컨설턴트님은 하루 네 잔, 거기까지만요. …제가 할게요.
(간 과장 앞의 서류가 줄어듦. 게이지 15% → 8%)
**[큰 칩 ③ 숨은 카페인 확인]**
면역 경비(6) — 단호하게, 정문에서 막으며: 신분증 보여주세요. 녹차, 콜라, 초콜릿, 에너지 음료. 전부 컨설턴트님 동료입니다.
(콜라·초콜릿에게 신분증 검사. 모두 '카페인 소속' 명찰.)
뇌 팀장(5) — 마지막 유혹에 흔들리며: 그래도 한 잔만, 더…
멜라토닌(7) — 처음으로 큰 목소리, 떨리지만 단호하게: …불, 끌게요!
(셔터가 내려오며 컨설턴트가 문 밖으로. 정적 1초.)

## 4막 · 결말 (약 25초) 〔정적 → 다정 → 마지막 최고 템포〕
[당직실 · 자막 '밤 11:40' · 불이 꺼지고 아데노신 서류 탑이 정리됨]
아데노신(8) — 울컥하며, 느리게: …저, 처음으로, 결재 받았어요.
뇌 팀장(5) — 쑥스럽게: 미안해요. 내가 계속 컨설턴트님만 불렀네요.
(간 과장이 컨설턴트 퇴근 게이지를 닦다가 조용히 컵을 건넴. 멜라토닌이 작게 엄지.)
[사내 공지 보드: 오늘의 3가지 — ① 커피 마감, 자기 6시간 전 ② 하루 한도 ③ 숨은 카페인 확인]
(인터뷰 · '멜라토닌 · 야간팀')
멜라토닌(7) — 떨리는 목소리: 저, 말했어요. …불 끄겠다고요.
[다음 날 아침 8:00 · 사무실 문 앞]
뇌 팀장(5) — 의기양양: 커피!
카페인 컨설턴트(9) — 명함에 도장 쾅, 능글능글: 오늘은 오후 두 시까지만 근무합니다~ 저도, 칼퇴하고 싶거든요~
(전 직원 박수, 간 과장 작게 웃음.)

## 확인받고 싶은 점
1. 주제가 카페인이어도 괜찮은지(캐릭터 개성 중심으로 골랐어요). 지난번 '커피+낮잠 쪽잠' 편과 각도는 달라요(밤 수면 vs 낮잠).
2. 개성 포인트(컨설턴트의 칼퇴 반전, 멜라토닌의 용기, 아데노신의 첫 결재, 간 과장의 조용한 감동)가 마음에 드는지.
3. 3가지(마감 시간, 하루 한도, 숨은 카페인)가 '금지·한도·확인' 구성으로 괜찮은지.
