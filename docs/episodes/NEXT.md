# 제작 대기열 (사용자 확정본만 올라온다)

> 정기 제작: 대기열 1번부터 제작한다. 치매·스트레스 편은 보류.

예약 실행은 시작할 때 이 파일을 읽고, **위에서부터 순서대로** 아직 업로드되지 않은 첫 항목의 대본을 그대로 제작한다
(해당 주제 영상이 채널 uploads 목록에 이미 있으면 건너뜀). 대화 세션이 이 파일을 관리한다
(예약 실행은 저장소에 쓰지 못한다). 대기열이 비면 실행이 직접 주제 인덱스 규칙으로 주제를 정해 새로 쓴다.

**주의(2026-11-02, 버그 기록):** 탈모 편을 대기열 1번으로 올린 바로 그날 당일 10:41 KST 실행이 이미 그 대본을 써서 제작·업로드했다
(아래 '제작 완료' 참고). 그런데 다음 날(11/2) 일회성 13:00 KST 실행 때는 대기열에 아직 1번(탈모, 이미 업로드됨)만 있고
2·3번(뇌졸중·심장)은 **그 실행이 저장소를 읽은 뒤에** 커밋돼서, 그 실행은 "1번은 이미 올라갔고 대기열에 더 없다"고
보고 자체 선정으로 다른 주제(음주 줄이기)를 만들었다. 즉 대기열에 올린 항목이 다음 실행 전에 이미 다른 실행에
쓰였는데도 치우지 않고 그대로 둔 게 원인 — **대본을 대기열에 올렸으면, 그게 실제로 쓰였는지(채널 uploads) 다음
실행 전에 반드시 확인하고 쓰였으면 바로 '제작 완료'로 내려야 한다.**
