## 확인받고 싶은 점
1. 등장인물: 장(장 대리)이 '소화팀'으로 위장 공장 라인까지 맡아요. 위장 전용 캐릭터를 새로 만들지 여부.
2. 인터뷰 컷 3번(장 대리, 간 과장, 뇌 팀장) 분량이 괜찮은지.
3. 엔딩 반전(라면 입고)이 좋은지, 다른 반전이 좋은지.
4. 영어판은 한국어 확정 후 같은 구조로 현지화(치킨→pizza 등)할 예정.
