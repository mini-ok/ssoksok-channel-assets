# 「짠맛 주의보, 심장 에이스의 혈압 게이지」 대본 초안 v1 (사용자 확인 완료 · 수정 없음 → 제작 대기)

- **반영한 피드백:** (1) 오프닝에서 전원이 한 마디씩 자기소개하지 않는다. 사건에 필요한 인물(개그 포함)만 등장한다. (2) 캐릭터 말버릇은 맥락에 맞을 때만 쓴다. '신분증 보여주세요'는 오프닝에서 빼고, 짠 음식이 정문을 통과하려는 장면에서만 쓴다.
- **주제:** 나트륨(소금). 주제 인덱스 규칙상 15번(해열제 오해)이지만 약 복용 안내로 번질 수 있어 건너뛰고, 아직 안 다룬 나트륨으로 바꿨다. 반대하시면 알려 주세요.
- **오늘의 3가지(정보는 딱 3개):** ① 하루 소금 5g(나트륨 2,000mg), 약 한 티스푼 안쪽 ② 라면 국물·소스·가공식품은 표시 확인 ③ 식탁 소금통 치우고 허브·향신료, 칼륨 든 저염 소금은 상황 보고.
- **수치(WHO 소금 줄이기 팩트시트에서 직접 확인):** 성인 권고 하루 나트륨 2,000mg 미만(소금 5g 미만, 약 한 티스푼). 성인 평균 섭취 4,278mg(소금 11g, 2021) = 권고의 두 배 넘음. 높은 나트륨 섭취는 혈압 상승과 연결, 줄이는 방법(소금통 치우기, 소스·즉석식품 줄이기, 허브·향신료, 칼륨 든 저염 소금 대체)도 WHO 안내.
- **한계(롱폼은 공지 한 줄):** 저염 소금은 칼륨이 들어 있어 신장 질환이 있거나 약을 먹는 분은 먼저 의료진과 상의. 쇼츠 본문에는 넣지 않고 설명란 '참고:' 줄로만.
- **출연(sid):** 해설 0, 심장 에이스 1(말버릇 "아직 뛸 수 있어요!"), 뇌 팀장 5("자, 정리해 보면…"), 장 대리 2(소문 전하기), 면역 경비 6(정문 장면에서만), 간 과장 3(엔딩 감동). 새 캐릭터 없음. 예상 길이 약 2분 10초~2분 40초(엔딩 카드 별도).
- **오프닝 설계(사건 하나로 시작):** 해설이 곧바로 사건을 터뜨리고 심장 에이스만 화면에 있다. 혈압 게이지가 오르면 그제야 뇌 팀장이 뛰어온다.
