# 「멜라토닌 과장의 불면 야근」(잠이 안 올 때, 근거 있는 습관 3가지) 대본 초안 v1 — 다음 회차 제안

- **반영한 피드백:** 오프닝 15초 안, 개그 중심 1개 + 엔딩 반전(치매 편 평가 반영), 되감기 구간은 CCTV 회상 효과, 대사는 1–2문장 약 30자, 출처 자막(기관 + 문서 + 연도), 원인은 가능성으로 말하기('~일지도 몰라요'), 3가지는 중요도 순.
- **주제를 고른 이유:** 수명 편(운동) 다음으로 '잠이 안 올 때'는 검색 수요가 크고, 만성 불면의 1차 권고가 약이 아니라 행동 요법(CBT-I)이라 '행동 3가지'로 풀기 좋다. 약 복용·치료 안내로 번지는 지점(수면제, 수면 제한 요법의 직접 시행)은 건너뛰고 '의료진 상담' 한 줄로만 다룬다. 이전 수면 7시간 편(멜라토닌 과장 칼퇴)과 겹치지 않게 '잠들기 어려움'에 집중.
- **제목 방향(효능 보장 금지):** 롱폼 「잠이 안 올 때 어떻게? 멜라토닌 과장의 불면 야근」 / 쇼츠 「누워도 잠이 안 오세요? 습관 3가지」.
- **오늘의 3가지(중요도 순, 제작 때 원문 재확인):**
  ① **기상 시간 고정:** 매일 같은 시간에 일어나기, 못 잔 날에도 늦잠 대신 평소 시간 유지. (NHS 불면증 안내, 2024-03 검토)
  ② **졸릴 때만 눕기:** 졸릴 때만 침대에 가고, 눕는 곳을 '잠자는 곳'으로 연결. (NHS 불면증 안내) ※ '20분 지나면 일어나기' 같은 세부 수치는 원문 확인 전이므로 제작 때 확인되면만 쓴다.
  ③ **취침 6시간 전부터 카페인·술·니코틴 피하고, 잠들기 직전 화면 끄기.** (NHS 불면증 안내)
- **원리·근거 문장(확인한 것):** 미국내과학회(ACP) 2016 지침(Annals of Internal Medicine): 만성 불면 장애 성인 모두에게 인지행동치료(CBT-I)를 1차 치료로 권고(강한 권고, 중간 수준 근거). 위 세 습관은 CBT-I와 수면 위생 안내의 기본 요소. NHS는 인지행동치료(CBT)를 대면 또는 온라인 프로그램으로 권하는 경우가 있다고 안내.
- **한계(롱폼 공지 한 줄 / 쇼츠 설명란 '참고:'):** 일반 정보이며 만성 불면(주 3회 이상, 3개월 이상 등 기준은 의료진 판단)이나 낮 졸림이 심하면 의료진 상담. 수면제 복용·중단은 다루지 않음.
- **출연(sid):** 해설 0, 멜라토닌 7(주연, 하품, 개그 1회: 불 끄러 갔다가 스스로 못 잠), 뇌 팀장 5(정리 실패), 아데노신 8 또는 카페인 9(③ 장면 한 번), 간 과장 3(엔딩 한마디). 새 캐릭터 없음. 길이 롱폼 2분 10초–2분 40초, 쇼츠 1편 50–60초.
- **영어 현지화:** "Melatonin's Sleepless Overtime", 'bedtime/wake time', 출처 'Source: NHS insomnia guidance (reviewed 2024) · ACP guideline 2016'.

# 쇼츠 1편 (한국어, 50–60초) — "누워도 잠이 안 오세요? 습관 3가지"
증상 3–4개(누우면 생각이 많아짐 / 새벽에 깸 / 늦잠 자고 또 못 잠) → 원인 '~일지도 몰라요' → 해결 3가지(기상 시간 고정 / 졸릴 때만 눕기 / 카페인·술·화면) → 반전(멜라토닌: 알람 맞췄더니 설레서 잠이 안 와요) → 엔딩 멘트.

## 확인받고 싶은 점
- (i) 3가지가 중요도 순인가: 기상 고정 → 졸릴 때 눕기 → 카페인·화면. (ii) '왜'는 ACP·NHS로 설명하되 메커니즘(졸음 신호)은 '~일지도 몰라요'. (iii) 행동이 일상 습관과 이어지는가. (iv) 반복 없음.
- 세부 수치(20분 규칙 등)는 원문 확인 후에만 사용합니다. 수정 지시가 없으면 이 초안대로 제작합니다.
