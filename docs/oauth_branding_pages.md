# OAuth 브랜딩 페이지에 넣을 내용 (복사해서 쓰세요)

구글 클라우드 "Google Auth Platform → Branding"에서 요구하는 항목과, 거기에 연결할 간단한 페이지 글입니다. 이 앱은 본인 두 채널에만 영상을 올리는 내부 도구이므로 아래 문구로 충분합니다. 법률 자문이 아니라 일반적인 예시 문구이니, 꼭 필요하면 본인이 검토해서 고쳐 쓰세요. 대괄호 [ ] 안은 본인 정보로 바꿉니다.

## 1. Branding 화면 입력값
| 항목 | 넣을 값 |
|---|---|
| App name(앱 이름) | 쏙쏙 영상 업로더 |
| User support email(사용자 지원 이메일) | 본인 이메일 |
| Developer contact(개발자 연락처 이메일) | 본인 이메일 |
| App logo(로고) | 비워도 됨 (구글 문서상 필수 표시 없음) |
| Application home page(홈페이지) | 아래 2번 페이지 주소 (예: 두 채널 중 하나의 주소 https://www.youtube.com/@ssoksok-health 도 가능한지 화면의 오류 메시지로 확인) |
| Privacy policy link(개인정보처리방침) | 아래 3번 페이지 주소 |
| Terms of service link(서비스 약관) | 아래 4번 페이지 주소 (같은 페이지의 다른 섹션이어도 됨) |
| Authorized domains(승인된 도메인) | 위 링크들이 들어 있는 도메인 (예: 구글 사이트 도구를 쓰면 화면이 알려 주는 도메인) |

구글 도움말에 따르면 외부(External) 앱을 프로덕션으로 올리려면 홈페이지·개인정보처리방침·서비스 약관 링크가 필요하고, 그 링크에 쓴 도메인은 "승인된 도메인"에 등록해야 합니다. 화면에 빨간 오류가 나오면 그 문구를 알려 주세요.

## 2. 홈페이지 글 (한국어 / English)
**쏙쏙 영상 업로더**
이 앱은 건강 정보 애니메이션 채널 "쏙쏙 건강백과"와 "Tiny Body Co."의 운영자가 두 채널에 영상을 자동으로 올리기 위해 만든 개인용 도구입니다. 일반 사용자에게 제공되는 서비스가 아니며, 채널 소유자 본인만 사용합니다.

**Ssoksok Video Uploader**
A personal tool used by the owner of the health-information animation channels "쏙쏙 건강백과" and "Tiny Body Co." to upload videos to their own channels. It is not offered to the public and is used only by the channel owner.

## 3. 개인정보처리방침 글 (한국어 / English)
**개인정보처리방침** (시행일: [오늘 날짜])
1. 이 앱은 YouTube Data API를 사용해, 채널 소유자 본인의 YouTube 채널에 영상, 썸네일, 설명, 재생목록, 댓글을 올립니다.
2. 앱이 접근하는 것은 소유자 본인이 승인한 본인 채널의 정보뿐입니다. 다른 사용자의 개인정보를 수집, 저장, 이용하지 않습니다.
3. 승인 과정에서 발급된 접근 토큰(리프레시 토큰)은 소유자의 비공개 환경 설정에만 저장되며, 제3자에게 공유하거나 판매하지 않습니다.
4. 이 앱의 YouTube API 이용에는 YouTube 서비스 약관(https://www.youtube.com/t/terms)과 Google 개인정보처리방침(https://policies.google.com/privacy)이 적용됩니다.
5. 소유자는 언제든 https://myaccount.google.com/permissions 에서 이 앱의 접근 권한을 철회할 수 있습니다.
6. 문의: [본인 이메일]

**Privacy Policy** (Effective: [date])
1. This app uses the YouTube Data API to upload videos, thumbnails, descriptions, playlists and comments to the YouTube channels owned by the app's owner.
2. The app accesses only information of the owner's own channels, as authorized by the owner. It does not collect, store or use any other person's personal data.
3. OAuth tokens issued during authorization are stored only in the owner's private environment settings and are never shared with or sold to third parties.
4. Use of YouTube API Services through this app is subject to the YouTube Terms of Service (https://www.youtube.com/t/terms) and the Google Privacy Policy (https://policies.google.com/privacy).
5. The owner can revoke the app's access at any time at https://myaccount.google.com/permissions.
6. Contact: [your email]

## 4. 서비스 약관 글 (한국어 / English)
**서비스 약관** 이 앱은 채널 소유자 본인이 자신의 YouTube 채널에 콘텐츠를 올리기 위한 개인용 도구이며, 일반 사용자에게 제공되지 않습니다. 앱은 있는 그대로 제공되며, 이용은 YouTube 서비스 약관(https://www.youtube.com/t/terms)을 따릅니다. 문의: [본인 이메일]

**Terms of Service** This app is a personal tool for the channel owner to publish content to their own YouTube channels and is not offered to the public. It is provided as is, and its use is subject to the YouTube Terms of Service (https://www.youtube.com/t/terms). Contact: [your email]

## 5. 이 글을 올릴 곳 (무료 예시)
- Google Sites(https://sites.google.com): 페이지 3개(홈페이지, 개인정보처리방침, 서비스 약관)를 만들고 "게시"하면 공개 주소가 생깁니다.
- 또는 Notion 공개 페이지, GitHub Pages 등 누구나 열어 볼 수 있는 주소면 됩니다. 로그인해야만 열리는 페이지는 안 됩니다.
- 올린 뒤 주소를 Branding 화면의 해당 칸에 붙여넣고, 도메인을 "승인된 도메인"에 추가하라고 하면 그대로 추가합니다.
