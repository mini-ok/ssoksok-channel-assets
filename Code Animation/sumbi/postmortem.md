# 〈숨비〉 회고 — 무엇이 문제였나 (2026-11-06)

결과: 2분 52초, 33컷 3D 셀 + 타이틀 + 크레딧 + Gemini 대사. 사용자 평가 "기존 콘텐츠보다 스토리와 비주얼 완성도가 떨어짐". 이번 작업은 1차 완성본에서 마무리.

## 결론 한 줄
**대사보다 "이야기가 요구한 연기"와 "코드로 만든 인물이 할 수 있는 연기" 사이의 격차가 가장 큰 원인이었다.** 여기에 사건 과밀(33컷, 컷당 약 5초), 동작이 아니라 정지 프레임으로만 검수한 과정이 겹쳤다. 대사는 부차적 원인.

## 1. 인물을 코드로 만든 것 — 주원인 (단, "코드"가 아니라 "사람 연기"가 문제)
- **이야기의 요구:** 솔이의 두려움 → 용기라는 내면 변화. 무릎 꿇고 끈 매어 주기, 물 붓고 퍼 담기, 웅크리기, 안기, 우비 벗기, 헤엄치기, 손잡기처럼 손과 물건이 닿는 사람 동작이 많았다.
- **코드 인형의 한계:**
  - 선반·캡슐로 조립한 몸이라 관절이 인형처럼 보이고, 손은 벙어리장갑, 실루엣은 뻣뻣했다.
  - 포즈는 관절 각도 몇 개를 숫자로 키잉한 것이라 예비 동작, 따라가는 동작, 무게 이동이 없다. 걷기·달리기도 사인파 사이클이다.
  - 손에 물건 들기와 손잡기는 IK 없이 위치를 끼워 맞춰서 공중에 떠 보였다(C12 물허벅, C16 첫 버전, 엄마의 손잡기).
  - 얼굴은 구 위 데칼이라 측면에서 뒤통수처럼 읽혔다(C3). 눈썹은 머리카락에 가려 감정 통로가 눈과 입 3가지뿐이었다. 위 속눈썹 선은 화난 눈매로 읽혔다.
- **허수아비와 비교:** 〈허수아비의 겨울〉은 "바람이 불 때만 움직인다"는 규칙으로 한계를 콘셉트로 바꿨다. 〈숨비〉는 같은 한계 위에서 실사 같은 사람 연기를 요구했다. 스킬 대원칙 2(감정 통로 2~3개, 캐릭터 규칙)를 이야기 단계에서 지키지 못했다.

## 2. 이야기 — 사건 과밀 (〈빛지기〉 교훈의 반복)
- 2:50에 33컷: 불턱, 웅덩이, 새는 물허벅, 갈림길 휘파람, 덩굴, 까마귀 코미디, 돌리 줌, 폭풍 회상, 휘파람 실패, 입수, 물속 롱테이크, 수면. 컷마다 약 5초라 장면 하나가 숏 하나로 끝났다.
- 정작 감정의 기둥은 숨 쉴 틈이 없었다. 솔이가 왜 바다를 무서워하는지(C26 폭풍 회상 2초로는 읽히지 않음), 왜 결심하는지, 엄마와의 재회가 그렇다.
- 까마귀 코미디는 톤을 흩트렸고, 꾸럭이와 솔이의 관계를 쌓는 시간을 빼앗았다.
- 시나리오는 종이 위에서는 좋았지만, 코드 애니메이션의 제작 단가(컷당 연기를 수작업 키잉)를 고려한 분량 설계가 아니었다.

## 3. 비주얼 — "손그림"보다 "게임 에셋"에 가까워짐
- 저폴리 형상(바위, 우비 선반, 몸통)의 각진 면을 id/normal 선이 그대로 따라가서 면이 드러났다. 거기에 3단 툰 램프가 겹쳐 PS2 게임 같은 인상이 났다. 이전 작품은 2D로 그린 디자인 형태라 이런 문제가 없었다.
- 바다는 정점 색 격자라 거품과 마루가 블록처럼 보였다. 구름은 평면 카드였다. 크레인 업 끝 장면에서 바다 무늬가 반복됐다.
- 3D 셀 본편과 2D 회화 플레이트 타이틀·크레딧의 질감이 서로 다르다.
- 비율이 맞지 않았다(솔이는 큰 머리, 엄마는 작은 머리).
- 카메라는 C30처럼 배우를 따라가는 조준점 방식이 잘 됐다. 나머지 다수는 "보이게만 하는" 실용적 구도였고, 구도를 설계하지 않고 엿보기(peek)로 고쳐 맞췄다.

## 4. 대사 — 부차적 원인
- 4줄, 짧았고, Gemini 연결 후 목소리 자체는 확보했다.
- 다만 나는 소리를 들을 수 없어 테이크를 길이·음높이 수치로 골랐다. 감정 연기의 적합성은 검증되지 않았다.
- 3D 얼굴의 2D 입모양 3단은 측면·원경에서 거의 읽히지 않았다.
- TTS 연결 문제(키·도메인)로 시간을 썼다. 오프라인 임시 음성은 품질이 낮았다.

## 5. 과정 — 검수 고리가 약했다
- 기술 시험(모델 시트, 물속 6초)까지는 샘플→컨펌을 지켰다. 본 제작은 "끝까지"라는 지시에 따라 33컷 연출을 한 번에 짜고 바로 렌더로 갔다. **애니마틱(회색 상자 + 타이밍 + 임시음) 확인 단계가 없었다.**
- 컷 검수는 정지 프레임 1~2장 위주였다. 동작의 리듬과 연기는 거의 보지 못했다(움직임과 소리를 직접 보고 듣지 못하는 한계).
- CPU 2코어에서 렌더가 약 3시간 걸렸다. 반복 수정 여유가 적었고, 고칠 때마다 "다시 렌더"가 비싸서 큰 수정 대신 작은 땜질을 했다.

## 다음 작품에 적용할 것
1. **이야기와 기법 적합성 검사를 기획 첫 단계에 둔다.** 인물 감정이 실루엣, 캐릭터 규칙, 환경(빛·바람·물)으로 읽히는 이야기를 고른다. 손과 물건의 접촉, 복잡한 생활 동작, 미묘한 표정이 핵심인 이야기는 피하거나 다른 기법을 쓴다.
2. **분량:** 2~3분에 10~14컷, 장소 1~2곳, 사건 3개 이하. 영웅 숏 4~6개에 시간의 대부분을 쓴다.
3. **사람이 꼭 필요하면:**
   - 2D로 그린 캐릭터(〈허수아비〉 cairo 파이프라인, 검증됨)를 3D 배경 위에 합성하는 하이브리드를 쓴다.
   - 또는 인형·가면처럼 뻣뻣함이 설정인 디자인으로 한다.
   - 또는 원경·실루엣 위주로 연출한다.
4. **애니마틱 먼저:** 회색 상자 + 카메라 + 타이밍 + 임시음을 저해상도 영상으로 만들어 사용자 확인 → 그다음 모델링·조명·마감.
5. **동작 검수:** 컷마다 저해상도 움직임 영상(또는 GIF)을 만들어 확인한다. 정지 프레임만으로 통과시키지 않는다.
6. **3D를 쓸 때는:** 면이 드러나지 않게 형상을 매끈하게(세분화) 하거나 면 경계 선을 끈다. 바다·하늘은 정점 격자 대신 그린 텍스처나 2D 플레이트로 한다. 타이틀까지 같은 질감으로 통일한다.
7. **대사가 있으면:** 이른 단계에서 사용자에게 테이크를 직접 들려주고 고르게 한다. 측면·원경 대사 컷은 피한다.
