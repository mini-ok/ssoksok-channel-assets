# 지식 쇼츠 주제 목록 (알쓸신잡풍)

예약 작업은 위에서부터 **상태가 `대기`인 첫 주제**를 골라 만든다. 만들고 올리면 상태를 `완료 (영상 ID, 날짜)`로 바꾼다.
각 주제의 숫자는 아래 출처에서 확인한 값이다. 만들기 직전에 출처를 한 번 더 열어 값이 그대로인지 확인하고, 다르면 출처의 값을 따른다.
출처를 확인할 수 없는 숫자는 화면에 쓰지 않는다. 주제가 떨어지면 같은 기준(공신력 있는 출처, 그림 한 장으로 비교가 되는 질문)으로 새 주제를 조사해 아래에 덧붙인다.
