# 〈점〉 아트 디렉션 브리프 (cel-anime-direction 1장 템플릿을 수묵에 맞춤)

1. **목표:** 조선 화실의 한 장 화선지 위에서 벌어지는, 먹과 물과 종이만으로 된 2분 단편. 접사 렌즈로 실제 종이를 찍은 것처럼 보여야 한다. 3D·모션그래픽·움직이는 일러스트·유체 시뮬레이션 데모 아님.
2. **결과물:** MP4 1920×1080, 1.85:1 레터박스(1920×1038 화면 영역), 24fps, 그림은 투스(12장/초). 약 2분 6초(본편 1:58 + 크레딧 8초).
3. **스타일 재료 어휘:** 화선지(섬유·닥 껍질 티·얼룩), 먹의 농담(초묵·농묵·담묵), 번짐, 마를 때 진해지는 테두리, 마른 붓의 비백, 창호지 너머 빛, 필름 그레인, 게이트 흔들림. 색은 거의 먹과 종이, 강조색은 등잔 호박색·낙관 주홍 둘뿐.
4. **등장 존재:** 점(먹 한 방울), 눈 없는 용(그림), 화가(창호지 위 그림자와 화면 밖), 빗방울, 튄 먹 자국. 사람의 몸·얼굴은 나오지 않는다.
5. **장면 비트:** 여정의 디딤돌은 매번 다른 장애물(첫 빗방울 → 자 밑 그늘 → 물줄기 질주 → 튄 먹 합류 → 비늘 밑 → 비 그침). 규칙 깨기는 세 단계.
6. **캐릭터 디자인**
   - **점:** 지금의 몸은 둥근 먹 웅덩이. 가장 진하고 젖어 윤기(반사광 한 점)가 있다. 지나간 자리는 들쭉날쭉한 옅은 얼룩.
     - 감정 통로: ① 가장자리 떨림과 번지는 속도 ② 진하기 ③ 윤기의 반짝임(살아 있음).
     - 규칙: 젖은 곳으로만 번진다, 번질수록 옅어진다, 먹과 합쳐지면 진해진다, 마르면 멈춘다. 예외는 단 한 번(C9).
   - **용:** 마른 붓으로 그린 수묵 용. 힘 있는 S자 몸통, 비백이 있는 비늘 획, 갈퀴 발톱, 수염. 눈자리는 윤곽만 있고 비어 있다. 글자 없음.
   - 모든 컷에서 같은 그리기 함수에서 나온다.
7. **선:** 선은 붓 획뿐이다(용, 자의 마디, 창살). 외곽선으로 그린 셀은 없다.
8. **채색:** 종이 위 먹의 흡수(농담). 색은 빛으로만 준다(등잔, 밤 푸른빛, 번개, 아침 금빛).
9. **배경:** 종이 자체가 배경이다. 화실 원경(C1, C11b)은 수묵담채로 그린 한 장(포스터컬러 재채색 대신 같은 먹·종이 렌더). 반복 금지: 섬유는 20mm 칸마다 다른 시드.
10. **조명 아크:** 등잔 호박색(C1~3) → 어둠과 창의 푸른빛, 번개(C4~8) → 비 그침, 구름 사이 은빛(C9) → 번개와 먹 폭풍(C10~11) → 창호 너머 아침 금빛(C12).
11. **이펙트:** 빗방울(떨어지는 순간 볼록한 물방울 2장 → 스밈), 들이치는 빗줄기(창 쪽 원경에만), 번개(창살 그림자를 종이에 던짐). 모두 2프레임마다 갱신.
12. **애니메이션:** 번짐은 투스. 예비 동작(0.25초 오그라듦) → 뻗음 → 홀드. 규칙 깨기는 키 + 긴 홀드. 용의 탈출만 빠르게, 스리스 금지(먹이 끊겨 보임).
13. **연출:** 고요한 도입 → 탄생과 판결 → 여정(점층) → 최저점(비 그침, 옅음) → 정적과 규칙 깨기 → 해방 → 아침의 한 획.
14. **금지:** CG 유체처럼 매끈한 흐름, 블룸·화이트아웃, 3D 카메라 이동(원근은 종이 평면 변환만), 흐릿한 원통처럼 미끄러지는 먹(시험 v2 실패), 빗살처럼 고른 붓 획(시험 실패), 물방울무늬처럼 고르게 흩은 빗방울, 사람 손·얼굴 실물.
15. **감정 목표:** 버려질 뻔한 얼룩이 가장 중요한 한 점이 되는 순간의 경이. 그리고 그 실수의 길이 그림으로 남는 조용한 만족.
16. **자체 검수:** 컷 묶음마다 원본 크기 크롭 시트 + 저해상도 움직임 영상. 스킬 3장 체크리스트 중 해당 항목 + 아래 추가 항목.
    - [ ] 점이 한 존재로 읽힘(윤기·예비 동작·카메라 조준)
    - [ ] 지나온 얼룩이 C12에서 한 획 그림처럼 읽힘
    - [ ] 종이 섬유가 배율이 달라도 같은 자리에서 같음
17. **이야기-기법 적합성:**
    | 필요한 동작 | 처리 |
    |---|---|
    | 붓을 들었다 거둠 | C1: 창호지 위 그림자. C2: 붓끝만(사물) |
    | 자·칼을 놓음 | 손 그림자 + 사물이 미끄러져 들어옴 |
    | 낙관 찍기·칼 거두기 | 결과만(컷 뒤에 이미 바뀌어 있음) + 아침 그림자 |
    | 점의 연기 | 번짐 파라미터(예비·뻗음·떨림·윤기) |
    | 용이 날아감 | 몸 선을 따라 먹이 미끄러져 종이 밖으로(평면 안에서) |
