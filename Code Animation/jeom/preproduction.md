확정: 결말 (c), 조선 화실. 출발 문서는 `ideas/2026-11-09_jeom_paru_story.md`, 기술 시험은 `ideas/tests/`.

## 1. 문제 점검과 해법

## 2. 완성도를 높일 방법

1. **종이 한 장 지도.** 모든 컷이 같은 종이 위 좌표(mm)를 공유한다. 구석(출발) → 자 → 튄 먹 → 비늘 밑 → 눈자리(도착). C5 부감에서 관객이 이 지도를 한 번 익히면 이후 접사가 어디인지 따라온다.
2. **해상도와 무관한 종이.** 섬유는 20mm 칸마다 시드로 만든다. 같은 자리는 어느 배율에서도 같은 섬유다. 번짐 모양(측지 도착 시간)은 단계마다 그 주변만 고해상도로 계산한다.
3. **애니마틱 먼저.** 실제 번짐 모델을 저해상도로 돌린 12컷 전체 + 카메라 + 임시음. 이야기 리듬과 "한 존재로 읽히는가"를 여기서 판정한 뒤에 고해상도로 간다.
4. **소리 설계를 이야기의 절반으로.** 대사·음악 없이 시작한다.
   - 빗소리와 섬유에 스미는 소리. 점이 번질 때마다 아주 작은 음 하나(같은 음계 안에서 단계마다 낮아짐 = 옅어짐).
   - 규칙을 깨는 C9는 완전 정적 + 섬유 당기는 소리 3번(허수아비 정적 기법).
   - 음악은 용이 눈을 뜨는 C10에서 처음 들어온다.
5. **검수 고리.** 컷 묶음(4컷)마다 원본 크기 크롭 시트 + 저해상도 움직임 영상. 컷 경계 앞뒤 프레임 확인(허수아비 6→6-1 교훈).
6. **타이틀·크레딧도 같은 먹.** 제목 '점'은 붓글씨 글꼴 모양을 먹 밀도로 넣어 같은 번짐 렌더로 찍는다. 크레딧은 허상공방 공용 코드(`_shared/credit_overlay.py`)를 쓰되 배경은 이 종이.

## 4. 스토리 문서에서 바뀐 점
- 비는 지붕 누수가 아니라 열린 창으로 들이친다.
- 점의 이동 = 번짐 사슬(몸의 중심이 옮겨 가고 얼룩이 남음). 결말 (c)의 "지나온 길"이 물리적으로 생긴다.
- 화가의 손은 그림자로만. 낙관은 결과로만.
- 용이 떠나는 방식 = 자기 몸 선을 따라 미끄러져 종이 밖으로.

## 5. 결정 사항 (2026-11-09 사용자 확인)
1. **낙관: 허상공방 白文 낙관.** 마지막 이미지가 크레딧으로 이어진다.
2. **악기: 거문고 = 점, 대금 = 용** (두 악기를 두 존재에 하나씩 묶는다).
   - 거문고: 조선 선비의 악기라 화실에 맞다. 술대로 치는 타악기적 소리와 음이 끊긴 뒤의 여백이 먹 한 점·번짐과 닮았다. 점이 번질 때마다 한 음, 갈수록 낮고 여리게(옅어짐), 끝은 퇴성으로 흘러내림.
   - 대금: 숨으로 소리를 내고, 청공에 붙인 갈대 속청이 떨어 특유의 음색을 낸다. 용의 눈에 생명(숨)이 들어가는 순간과 맞는다. 눈이 뜨이는 C10에서 처음 등장하고 청의 떨림이 커지며 용이 떠난다.
   - 규칙 깨기(C9)는 두 악기 모두 없음. 결말 C12는 거문고 한 음 + 대금 여운.
   - 스케치: `audio/sketch.py`. 음색은 사용자가 들어 보고 확정한다(Claude는 소리를 들을 수 없음).
3. **용:** 형태는 모델 시트 v1을 유지. 접사로 보이는 머리·발톱만 획을 더 쌓아 무게를 준다.

## 6. 진행 순서와 확인 지점(스킬 7장)
1. 브리프 + 씬 리스트 + 종이 지도 ← 이번 차례
2. 모델 시트(용, 점의 상태, 화실) → **확인**
3. 애니마틱 → **확인**
4. 대표 프레임 4장 + 짧은 움직임 시험 → **확인**
5. 컷 묶음별 제작(묶음마다 시트 + 저해상도 영상)
6. 사운드 → 전체 렌더 → 검수 → 전달 → 저장소 → 스킬 노하우 갱신
