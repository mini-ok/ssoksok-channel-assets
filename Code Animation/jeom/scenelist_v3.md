## 클라이맥스의 감정 흐름
생명을 얻는다 → 움직이려 하지만 종이에 묶여 있다 → 비에 젖어 가는 종이를 벗어나려 애쓴다(두 번 실패, 먹이 씻겨 옅어짐) →
바닥에서 멈춘다 → 눈빛이 다시 켜지고 마침내 벗어난다 → 창가에서 잠든 화가를 돌아본다 → 창을 넘어 빗속으로 →
폭풍 속에서 먹이 씻겨 내려가도 버틴다 → 포효 → 먹구름이 몸으로 빨려 들어 하늘을 차지한다 → 승천, 구름이 갈라지고 붉은 해가 뜬다(영화의 첫 색).
