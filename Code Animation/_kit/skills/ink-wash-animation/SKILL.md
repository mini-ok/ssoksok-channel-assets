# 수묵 코드 애니메이션: 연출·제작 스킬

종이에 먹이 스미고 번지는 그림이 살아 움직이는 단편을 **코드만으로** 만들 때 쓴다(모델·텍스처·음원 소스 없음).
참고 구현: GitHub `mini-ok/ssoksok-channel-assets` → `Code Animation/jeom/`(〈점〉, 3분 11초, 1080p).
이 스킬은 작품을 만들 때마다 새로 검증된 노하우를 6·7장에 누적한다. 대본·컷 리스트는 대본 스킬로 먼저 만든다.

## 0. 대원칙
1. **모든 것은 종이 위의 먹이다.** 화면 좌표가 아니라 종이 mm 좌표로 그린다(`paper.View(cx, cy, width_mm, W, H)`). 같은 종이 상태를 어떤 화면(원경·근접)으로 봐도 일치해야 한다.
2. **한 장면의 상태는 한 원천에서.** 점이 지나온 길·젖은 자국·흩뿌린 먹 같은 흔적은 한 번 계산해 저장하고(npz) 모든 컷이 같은 것을 읽는다. 컷마다 따로 그리면 "앞에서 있던 흔적이 사라졌다가 엔딩에 다시 나온다"는 지적을 받는다.
3. **디지털 선처럼 보이면 실패.** 비·칼자국·빛줄기는 붓 결(이방성 잡음, 섬유에서 끊김, 먹색)로 그린다. 흰 선, 균일한 직선, 원판 해(국기처럼 보임)는 거부당했다.
4. **도구가 혼자 움직이지 않는다.** 칼·붓은 반드시 쥔 손(또는 화면 밖으로 이어지는 손잡이 + 손 그림자)과 함께. 시점 컷 앞에서는 인물의 **몸**이 다가가야 다음 시점 컷이 붙는다(손만 뻗으면 안 됨).
5. **연속성.** 컷 경계 앞뒤의 위치·크기·상태(흔적, 눈동자 모양, 팔 개수, 조명)를 반드시 맞춘다. 모양이 바뀌어야 하면 바뀌는 과정을 보여 준다(예: 번진 먹 덩어리가 안쪽으로 모여 둥근 눈동자가 됨).

## 1. 작업 순서(사용자 지시)
1. 새 기법·새 연출은 **작은 샘플**(정지 프레임 몇 장 → 540p 짧은 움직임 + 소리)로 먼저 확인받는다. 컨펌 전에 1080p 전체 렌더를 시작하지 않는다.
2. 샘플 이미지는 **실제 전달 크기**로 직접 열어 보고 보낸다(확대 크롭만 보고 판단하지 않기).
3. 해석이 두 갈래인 요청(예: "비가 부감 쪽에서")은 두 시안 정지 화면을 나란히 보여 주고 고르게 한다.
4. 길이를 채우려고 같은 장면·대사를 반복하지 않는다.
5. 공개 저장소에는 사용자 고유의 시나리오 작법 용어를 쓰지 않는다(씬 리스트는 장면 설명만).

## 2. 파이프라인(〈점〉 기준)
- 배율: `JEOM_SCALE=1`(960×540, 시험) / `2`(1920×1080, 최종). 캐시는 배율 접미사(`_1920`)로 분리.
- 그림은 투스(12장/초)로 그리고 24fps로 인코딩. 컷 표 `CUTS`(컷 이름, 종류, 시작, 길이)와 `frame(k)` 하나로 렌더.
- 상태가 있는 컷(유체·먹 번짐 누적)은 **한 프로세스에서 처음부터 순서대로**. 프레임을 건너뛰고 이어 그리면 상태가 틀어진다.
- 메모리 8GB에서 무거운 렌더는 두 프로세스까지(세 개는 OOM). 두 프로세스가 같은 캐시를 동시에 처음 만들면 깨진 파일을 읽는다 → 첫 캐시는 단독으로.
- 문자열 키 캐시는 코드를 바꿔도 옛 그림을 재사용한다 → 그림 로직을 고치면 관련 캐시를 지운다.
- 큰 판(수천 px)에 작은 덩어리를 많이 그릴 때 화면 전체 격자를 매번 만들지 말 것(`View.grid_mm_crop`): 20분 → 1분.

## 3. 검증된 엔진 조각(`jeom/engine/`)
| 파일 | 하는 일 | 핵심 |
|---|---|---|
| `paper.py` | 한지 섬유·얼룩·색 | `paper_layers(view)` → 섬유 fib가 먹 번짐·붓 끊김의 결이 된다 |
| `brush.py` | 붓 획 `Stroke`, 담묵 `Wash` | 압력 곡선(press), 마른 붓 비백(dry), 붓털 결. 제목 글씨도 이걸로 쓴다 |
| `inkmm.py` | 먹이 물길 따라 번지는 점 | 측지 거리 도착 시간 + 단계(STAGES), 칼자국은 field.cost 장벽 |
| `rain.py` | 붓 비 | `InkRain`(평면 3겹), `RadialRain`(원근) |
| `room.py` | 화실 원경 | 정규 좌표 실루엣, 등잔 벽 그림자, 새벽 햇살, 창밖 비. 밤엔 종이 소품도 어둡게(`amb`) |
| `after.py` | 폭풍 뒤 아침 종이 | 어느 View든 같은 상태(구름·흘러내린 먹 줄기·흩뿌린 먹·젖은 자국) |
| `scale.py` | 배율·해상도 | `W, H, S, SUF` |

## 4. 그림이 살아 움직이는 리그(그린 용 그대로)
- 그림의 모든 획 점을 등뼈 좌표 (s: 머리에서 잰 길이, a: 접선, d: 법선)로 바꿔 둔다. 머리 획은 s=0 틀에 고정.
- 새 등뼈 = **머리가 지나온 길**(trail). 몸은 그 길을 따라간다(뱀처럼). 떠 있을 때만 제자리 물결 모양.
- 빌보드 틀 `frame_along`: N = 시선 × T. 몸이 시선 방향으로 곧장 나아가면 단면이 사라져 한 점으로 눌린다 → **감아 돌며(나선) 멀어지게**.
- **길이 ≥ 몸 길이**여야 한다(배율 포함). 짧으면 몸이 시작점에 뭉쳐 엉킨다 → 지나온 길을 더 길게 잡는다.
- 뒤집기: 거울 반전을 0.45초 동안 `cos(π·ease)`로 굴린다(한 프레임에 뒤집으면 "튄다"). 고개를 돌릴 때 머리 앞뒤 길이를 단축(`fore`)해야 장대처럼 안 보인다.
- 꼬리 휘두르기 같은 국소 변형은 위치만 바꾸고 **매개변수 길이(cum)는 그대로** 둔다(늘어난 길이에 몸이 모자라지 않게).
- 앞발이 둘이면 반대편 팔을 법선 반전·약간 뒤로 복제(`ARM2`).
- 살아 있는 변형: 숨(법선 부풀기), 수염 흔들림(뿌리 회전), 발톱 오므림, 턱 경첩 회전, 부분 들림, 배율.

## 5. 카메라·합성
- 원근은 카메라 원점·+z 시선의 핀홀(`project`). 배치 배율은 **그리기 전에** 등뼈 x·y와 단면에 곱한다(그린 뒤 축소하면 화면 밖 부분이 잘려 머리가 사라진다).
- 창 넘기: 창 평면을 넘은 부분만 창 안쪽 마스크로 자르고, 아직 방 안인 몸 띠는 그대로. 멀수록 빗속 안개. 어두운 벽 앞 몸에는 창 쪽 가장자리 푸른 테두리 빛(밝은 창 앞에서는 실루엣 그대로).
- 큰 줌: 같은 종이를 세 배율 판(먼·중간·눈)으로 만들어 카메라 폭에 맞는 판을 겹쳐 넘긴다. **한 고정점을 중심으로 한 번에 줌**(중심 이동과 배율이 따로 놀면 움직임이 중간에 바뀐다). 덧그림(눈물 테 등)은 모든 판에 같은 식으로.
- 종이 바깥(책상)이 프레임에 들어오면 검게 보인다 → 의도가 아니면 종이 안쪽만 잡는다.
- 시점 컷의 눈물: 보는 사람 눈(카메라 바로 앞)에서 떨어지므로 착지점 바로 아래에서 크고 흐리게 나타나 착지점으로 모이며 작아진다(렌즈 굴절·하이라이트). 착지 전 종이에는 아무 흔적도 없게.

## 6. 비·빛·하늘
- 붓 비 3겹: 담묵 빗발 안개(넓은 결) / 넓은 띠 × 가는 붓털 결 / 가까운 굵은 획. 주기적 FFT 이방성 잡음이라 이음매 없음. 번개 때도 먹색. 유체로 빗줄기를 휘게 하면 마블링처럼 보여 끈다.
- 원근 비 `RadialRain`: 같은 결을 (각도 × log 반지름)에 감는다. 앞쪽 굵은 방울은 짧고 넓게, 화면 가장자리에만. **아쉬움(사용자)**: 하늘을 정면으로 올려다보면 비가 한 점에서 퍼져 보인다 → 다음엔 카메라를 기울여 소실점을 프레임 밖(위)에 두고, 바람으로 층마다 소실점을 조금씩 다르게.
- 해: 원판이 아니라 금빛 번짐 + 빛줄기 + 구름 테. 구름 테 빛은 구름 덩어리를 흐린 뒤 경계에서만(종이 결이 금가루처럼 반짝이지 않게).
- 상징의 연결: 용이 한 점으로 사라진 바로 그 자리에 빛의 점 → 정적 → 해가 터져 나옴(설명 없이).
- 렌즈를 치는 순간: 짧은 흔들림·번쩍 + 렌즈 위 흐린 먹 방울이 흘러내리며 옅어짐(작고 적게 — 많으면 먼지처럼 보임).

## 7. 소리(numpy 합성, `anim_audio3.py`, `audio/instruments.py`)
- 갈래를 나눈다: 음악 / 효과 / 바탕(비·새). 정적은 **음악 갈래만** 곡선으로: 마른 소리 40ms 코사인으로 멎고 울림은 250ms로 닫고, 다시 들어올 때 첫 타격 직전 10ms. 0을 곱해 뚝 끊거나 빗소리를 바꿔 끼우면 지직거린다.
- 천둥 등 긴 소리는 꼬리를 곡선으로 닫는다. 검사: 경계 ±5ms의 5kHz 이상 피크 / 앞 200ms 수준.
- 거문고: 도파관 줄(3탭 손실 필터 = 명주실), 술대 타격(친 자리 빗살 + 대모 '딱' + 판 '덕'), 오동나무 울림통 공진 6개, 농현·퇴성은 다시 표본(재생 속도). 북: 원형 막 모드 + 친 직후 음높이 처짐 + 통 울림 + 북채.
- 대금은 이 작품 결에 안 맞았다. 긴장은 거문고 호흡 변화 + 북 "둥. 둥." + 대현 낮은 음 쌓기.

## 8. 제목·크레딧
- 제목은 붓 엔진 획 목록으로 직접 쓴다(획마다 압력·비백·꼬리). 종이에 스며들게(흐린 먹 → 선명한 먹). 손 없이 획이 혼자 그어지는 연출은 피한다.
- 낙관은 인주가 묻은 곳만 종이에 곱한다(흰 바탕 테두리 없이). 크레딧은 명조(Noto Serif CJK KR), 타자 효과·소리 없음. 제목이 우상단이면 낙관은 좌하단, 그 오른쪽에 크레딧.
