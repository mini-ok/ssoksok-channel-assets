# 콘텐츠 기획서 작성

md/0.콘텐츠기획요청.md 는 "3D 미술 전시 갤러리"라는 특정 분야로 고정된 요청서였다. 이 스킬은 그 구조를 재사용하되, 분야를 고정하지 않고 매번 사용자에게 필요한 정보를 물어본 뒤 그 분야에 맞는 콘텐츠 기획서를 작성한다.

## 1. 정보 수집

사용자의 요청 문장에 이미 답이 포함되어 있으면 다시 묻지 않는다. 빠진 항목만 AskUserQuestion으로 질문한다 (한 번에 최대 4개).

**필수 질문**
- 분야/장르: 어떤 콘텐츠인가 (예: 미술/전시, 역사·문화 전시, 제품·브랜드 쇼케이스, 교육/체험 콘텐츠, 게임 등 — 자유 입력도 허용)
- 간단한 기획 컨셉: 핵심 메시지·목적을 한두 문장으로

**선택 질문 (분야상 필요할 때만)**
- 실행 환경/플랫폼 (PC, VR, 모바일 등)
- 제작 도구 (예: Unreal Engine 버전, Unity 등)
- 공간·콘텐츠 구성 (섹션/방 개수, 등장인물 등)
- 타겟 사용자/관람객
- 결과물 저장 위치 — 프로젝트에 `design/` 폴더가 있으면 기본값으로 `design/콘텐츠기획.md` 제안, 없으면 위치를 물어본다

## 2. 역할

수집한 분야에 맞춰 "10년차 [분야] 콘텐츠 기획자"로 역할을 설정하고 기획서를 작성한다. (예: 분야가 전시면 전시기획자, 게임이면 게임 콘텐츠 기획자)

## 3. 문서 구성

아래 템플릿을 기본으로 하되, 분야에 맞지 않는 항목은 자연스럽게 용어를 바꾸거나 생략한다.

### 1) 시나리오 기획
- 컨셉 및 기획 의도: 핵심 메시지와 목적 정의
- 타겟 사용자 정의: 누구를 위한 콘텐츠인지 분석
- 사용자 동선(User Flow): 진입 → 경험 흐름 → 퇴장까지의 여정 설계
- 사용자 인터랙션: 사용자에게 유도할 행동 정의

### 2) 콘텐츠 기획
- 콘텐츠 라인업(스펙): 이미지·오디오 등 에셋 목록 및 메타데이터
- 공간/화면 테마 및 배치: 섹션별 무드(색상, 조명 등)와 콘텐츠 배치 위치
- 스토리텔링 및 텍스트: 설명 스크립트, 안내 텍스트(Wall Text 등), 팝업 안내문
- 기술 사양: 지원 플랫폼
- 콘셉트 이미지 / 무드보드
  - 역할: 전체 분위기·색감·조명 느낌을 한눈에 보여주는 이미지 모음
  - 포함 내용: 레퍼런스 이미지, 색상 팔레트, 폰트 스타일, 조명 효과 예시
  - 가능하면 실제 콘셉트 이미지를 생성해 `Concept/` 폴더에 저장
- 공간 레이아웃 / 스토리보드
  - 역할: 사용자 시선 이동에 따른 화면 연출과 인터랙션 흐름을 시각적으로 설계
  - 포함 내용: 평면도(2D Layout), 주요 화면 스케치/와이어프레임, 인터랙션 연출 과정
  - 가능하면 흑백 콘티 시트 형식의 스토리보드 이미지를 장면별로 생성해 `Storyboard/` 폴더에 순서 번호 + 장면 제목을 파일명으로 저장

## 4. 작성 및 저장

- 위에서 정한 경로(기본 `design/콘텐츠기획.md`)에 문서를 작성한다.
- 이미지 생성이 불가능한 환경이면 이미지 항목은 텍스트 설명(레퍼런스 설명, 구도 설명 등)으로 대체하고, 이미지 생성이 필요하다는 점을 사용자에게 안내한다.

## 5. 다음 단계

콘텐츠 기획서 작성이 끝나면 용도에 따라 이어갈 스킬을 안내한다.
- 언리얼·유니티 등 게임 엔진으로 실제 구현할 계획이면 시스템 기획서(AGENTS.md, 기획기본구조.md, Task/Checklist, 단계별수행절차.md)를 만드는 [[system-plan]] 스킬
- PPT, 기획안, 지원사업 신청서 등 사람에게 보여줄 문서·발표 자료가 목적이면 [[proposal-plan]] 스킬
