# 시나리오 신규 집필 스킬

아이디어 한 줄에서 초고까지 **단계를 밟아** 쌓아 올린다. 각 단계의 산출물이 다음 단계의 설계도가 되며, 앞 단계가 합의되지 않으면 다음 단계로 넘어가지 않는다.

## 대원칙

1. **작가가 주인이다.** 선택지를 제시하고 추천하되, 결정은 사용자가 한다. 사용자의 아이디어를 내 취향으로 바꿔치기하지 않는다.
2. **단계마다 멈춘다.** 각 단계 끝에서 산출물을 보여주고 승인을 받는다. 사용자가 "한 번에 쭉 가"라고 하면 그때만 연속 진행한다.
3. **작게 쓰고 크게 고친다.** 로그라인·시놉시스처럼 짧은 단계에서 방향을 충분히 흔들어 본다. 초고 단계에서 전제를 바꾸면 비용이 크다.
4. **스토리 바이블이 기준이다.** 모든 단계에서 확정된 사항은 `story-bible.md`에 누적한다. 이후 단계는 바이블과 충돌하면 안 된다.
5. **모르는 건 묻는다.** 사용자가 정하지 않은 핵심 설정(결말, 주인공의 선택 등)은 임의로 확정하지 않고 선택지로 제시한다.

## 시작할 때 파악할 것

원하는 출발점을 먼저 확인한다. 사용자는 어느 단계에서든 시작할 수 있다 (예: 이미 로그라인이 있으면 3단계부터).

- 지금 가진 것: 아이디어 한 줄 / 로그라인 / 시놉시스 / 트리트먼트
- 장르와 톤, 참고 작품 ("〇〇의 긴장감 + △△의 정서")
- 목표 러닝타임, 예산 규모 감 (저예산 독립 / 중급 상업 / 대형 상업)
- 용도: 공모전, 영진위 등 지원사업, 제작사 제안, 본인 연출작
- 제출처가 있으면 요강의 요구 서류와 분량 (요강은 사용자에게 받고, 추측하지 않는다)
- 반드시 넣고 싶은 장면·이미지·대사, 반드시 피하고 싶은 것

## 1단계: 아이디어 개발

아이디어가 한 줄뿐일 때 쓴다.

- 아이디어를 **"만약 ~라면?"** 질문 3~5개로 확장한다.
- 각 질문마다 가능한 주인공, 핵심 갈등, 장르적 재미를 짧게 붙인다.
- 이 이야기의 **핵심 질문**(관객이 끝까지 궁금해할 것)과 **주제 질문**(작품이 붙들고 있는 삶의 질문)을 구분해 적는다.

**산출물**: 방향 후보 3~5개 표 → 사용자가 하나(또는 조합)를 고른다.

## 2단계: 로그라인

- 형식: 주인공(결함이 드러나는 수식어 포함) + 도입 사건 + 목표 + 장애물·판돈. 한 문장, 가능하면 40자 안팎, 길어도 두 줄.
- **3~5개 버전**을 톤·초점을 달리해서 낸다 (장르 중심 / 인물 중심 / 아이러니 중심).
- 각 버전에 한 줄 자평: 이 버전이 약속하는 영화는 무엇인가.

점검:
- [ ] 주인공이 능동적으로 무언가를 원하는가
- [ ] 장애물이 주인공의 결함과 맞물리는가
- [ ] 듣는 순간 포스터와 예고편이 떠오르는가
- [ ] 비슷한 기존 작품과 무엇이 다른가 (차별점 한 줄)

## 3단계: 기획의도와 캐릭터 바이블

### 기획의도 (A4 반 장 이내)

- 왜 이 이야기인가 (작가의 개인적 출발점)
- 왜 지금인가 (시대·관객과의 접점)
- 관객이 극장을 나서며 가져갈 감정 한 가지

### 캐릭터 바이블

주요 인물마다:

| 항목 | 내용 |
|---|---|
| 이름 / 나이 / 직업 | |
| 외적 욕망 (want) | 영화 안에서 쫓는 구체적 목표 |
| 내적 결핍 (need) | 본인은 모르지만 바뀌어야 할 것 |
| 상처 (wound) | 결핍을 만든 과거 |
| 거짓 믿음 | 상처가 남긴 잘못된 신념 |
| 아크 | 시작점 → 끝점 |
| 말투 | 어휘, 존댓말 수위, 말버릇. **샘플 대사 3줄** |
| 주인공과의 관계 | 주인공에게 어떤 압력을 주는가 |

- 적대자는 **자기 입장에서 옳은 이유**를 반드시 적는다.
- 조연끼리 기능이 겹치면 합치기를 제안한다.

## 4단계: 시놉시스

- **짧은 시놉시스**(A4 반 장, 제출용)와 **긴 시놉시스**(A4 2~3장, 작업용)를 구분한다. 용도에 따라 하나만 써도 된다.
- 결말까지 쓴다. 시놉시스에서 결말을 숨기지 않는다.
- 막 구조가 드러나게 쓴다: 도입 사건 → 1막 전환 → 중반 전환 → 최저점 → 클라이맥스 → 결말.
- 산출 후 **구조 점검표**를 붙인다: 각 전환점의 내용과 대략의 위치(러닝타임 대비 %).

## 5단계: 트리트먼트

- 시퀀스 단위로 산문으로 쓴다 (장편 기준 대략 8시퀀스 안팎, 이야기에 따라 조정).
- 각 시퀀스 머리에: **시퀀스 제목 / 주인공의 목표 / 가로막는 것 / 끝날 때 바뀐 것**
- 핵심 대사나 이미지가 이미 떠오르면 괄호로 메모해 둔다.
- 이 단계에서 **정보 공개표**(스릴러·미스터리)와 **복선·회수 목록**을 바이블에 만든다.

## 6단계: 씬 리스트 (스텝 아웃라인)

| S# | 장소 / 시간 | 등장인물 | 씬의 목적 | 갈등 | 끝날 때 바뀐 것 | 예상 분량 |
|---|---|---|---|---|---|---|

- 모든 씬은 **'끝날 때 바뀐 것'**이 있어야 한다. 비어 있으면 합치거나 뺀다.
- 예상 분량 합계를 목표 러닝타임과 대조한다 (시나리오 1쪽 ≈ 1분을 대략의 기준으로).
- 같은 장소·같은 인물 조합이 연속되면 리듬을 점검한다.

## 7단계: 초고 집필

- 씬 리스트를 따라 **시퀀스 단위로** 쓴다. 시퀀스 하나를 끝내면 보여주고 계속할지 묻는다.
- 초고의 목표는 끝까지 가는 것이다. 한 씬을 완벽하게 다듬느라 멈추지 않는다. 고민되는 지점은 `[메모: …]`로 남기고 진행한다.
- 쓰다가 씬 리스트와 달라지면, 달라진 점을 시퀀스 끝에 적고 바이블을 갱신한다.
- 시퀀스를 넘길 때마다 확인: 앞 시퀀스에서 심은 복선, 인물이 지금 아는 정보, 감정의 온도.

## 8단계: 초고 자가점검과 인계

초고가 끝나면 아래를 점검해 짧은 리포트로 붙인다.

- [ ] 로그라인이 약속한 영화가 되었는가
- [ ] 주인공이 클라이맥스에서 스스로 선택하는가
- [ ] 복선·회수 목록에 미회수 항목이 없는가
- [ ] 인물 이름·호칭·나이·설정이 일관적인가
- [ ] 분량이 목표와 맞는가
- [ ] 남은 `[메모]` 목록

그다음 단계로 **screenplay-revision 스킬로 1고 진단**을 제안한다.

## 한국 시나리오 서식 규칙

- 씬 머리: `S#12. 경찰서 취조실 (밤)` — 번호, 장소, 시간. 실내·실외 구분이 필요하면 `(내/밤)`.
- 지문: 현재형. 카메라에 보이고 마이크에 들리는 것만 쓴다. 한 문단 3줄 이내.
- 대사: `인물명` 다음에 대사. 괄호 지시는 꼭 필요할 때만 `(작게)`, `(사이)`.
- 화면 밖 소리 `(E)`, 내레이션 `(Na.)`, 보이스오버 `(V.O.)`, 전화 목소리 `(F)`.
- `인서트`, `몽타주`, `플래시백`, `(C.U.)` 등은 필요할 때만 쓴다.
- 인물 첫 등장 시 이름 옆에 나이와 한 줄 인상: `민재(34, 형사. 넥타이를 느슨하게 맨 채 잠을 못 잔 얼굴)`

## 대사와 지문 원칙

- 인물은 원하는 것을 직접 말하지 않는다. 다른 말을 하면서 원하는 것을 향해 움직인다.
- 관객에게 필요한 정보는 갈등 속에서 흘린다. 두 인물이 서로 아는 사실을 설명하게 하지 않는다.
- 인물마다 어휘, 문장 길이, 존댓말 수위, 말버릇을 달리한다. 캐릭터 바이블의 샘플 대사를 기준으로 삼는다.
- 감정은 형용사보다 행동으로 쓴다.
- 씬은 최대한 늦게 들어가서 일찍 나온다.

## 장르별 설계 포인트

- **스릴러·미스터리**: 정보 공개표를 트리트먼트 단계에서 먼저 설계한다. 공정한 단서, 반전이 앞 장면을 다시 보게 만드는 구조, 범인·진상의 동기.
- **로맨스(SF 로맨스 포함)**: 두 사람이 끌리는 이유가 장면으로 보여야 한다. 장애물은 외부와 내면 양쪽에. SF 설정은 관계의 은유로 작동하게 하고, 설정 규칙은 로그라인 단계에서 확정한다.
- **코미디**: 웃음은 인물의 욕망과 결함에서 나온다. 셋업·페이오프 목록을 복선 목록과 함께 관리한다.
- **사극**: 고증과 허구의 경계, 시대어 사용 기준, 신분에 따른 호칭·경어 규칙을 바이블에 먼저 정해 둔다. 역사적 결말을 아는 관객에게 긴장을 어떻게 만들지 기획의도 단계에서 정한다.

## 피해야 할 것

- 번역투, 설명투 지문 ("그녀는 무언가를 결심한 듯한 표정이다")
- 인물이 자기 감정을 정확한 단어로 분석하는 대사
- 모든 씬을 여운 있는 한마디로 끝내는 습관
- 같은 비유와 수식어의 반복
- 사용자가 정하지 않은 결말·교훈·화해를 임의로 확정하기

## 산출물

- 각 단계 산출물은 대화 안에서 먼저 보여준다.
- 스토리 바이블은 `story-bible.md`로 누적 관리한다 (screenplay-revision과 같은 파일을 공유).
- 제출용 문서(기획의도·시놉시스·인물 소개 묶음)나 완성 초고를 Word 파일로 원하면 docx 스킬을 읽고 한국 시나리오 서식으로 조판한다.
- 파일명 예: `작품명_시놉시스_2026-09-30.docx`, `작품명_초고.docx`
