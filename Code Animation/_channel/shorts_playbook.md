# 허상공방 쇼츠 만들기·올리기 (언제든 다시 쓰는 방법)

쇼츠는 두 갈래다. 둘 다 목적은 **롱폼 단편으로 시청자를 데려오는 것**이다.

| 갈래 | 무엇 | 도구 | 길이 |
|---|---|---|---|
| A. 작품 예고 쇼츠 | 롱폼 단편에서 잘라 낸 세로 영상 | `tools/make_teaser_short.py` | 25~45초 |
| B. 종이 지식 쇼츠 | "종이로 보는 자연의 질서" 상식 모션그래픽 | `haedal/` `simhae/` `hive/` + `tools/render_paper_short.sh` | 50~60초 |

공통 원칙
- 쇼츠에서 누를 수 있는 링크는 **'관련 동영상' 하나**다(설명란·댓글 링크는 눌리지 않음). 모든 쇼츠에 이어 볼 롱폼을 건다.
- 길이를 채우려고 같은 장면을 반복하지 않는다. 짧으면 짧은 대로 올린다.
- 화면 글자는 **영어와 한글을 비슷한 크기로** 함께 쓴다(예고 쇼츠 A-3, 지식 쇼츠 B-2a). 한글이 크면 한국 전용 채널처럼 보인다(사용자 지시 2026-11-21: 예고 쇼츠와 일반 쇼츠 모두).
- 영어판 수치는 미터·피트(킬로미터·마일)를 함께 쓴다.
- 하루에 여러 편이면 **4시간 간격**으로 나눠 예약한다.

## A. 작품 예고 쇼츠

### A-1. 구간 고르기
롱폼 전체를 다 보여 주지 않는다. 다음 셋이 맞는 20~45초를 고른다.
1. 앞 맥락 없이 바로 이해되는 장면으로 시작한다(예: 등대 불이 꺼지는 순간).
2. 구간 안에 한 번의 변화가 있다(오해가 생김, 위기가 닥침).
3. 결말은 보여 주지 않는다. 궁금한 순간에 끊고 '전체 이야기는 관련 동영상에서'로 넘긴다.

같은 작품에서 두 편을 뽑아도 된다(허수아비: 오프닝의 오해 편 + 눈보라 편).

### A-2. 화면 구성 (make_teaser_short.py)
- 1080×1920 세로. 원본 가로 화면에서 **4:3 부분을 잘라** 가운데(y 520~1330)에 놓는다. 뒤 배경은 같은 화면을 크게 흐려 어둡게 깐다.
- 크롭 위치 `x`는 시간식으로 옮길 수 있다(주인공이 화면 밖으로 나가는 구간만 크롭을 이동). 예: `"if(gte(t\\,29)*lt(t\\,32)\\,60\\,240)"`.
- 위: 작은 표지 `Dreamloom Studio · 허상공방` → 첫 자막(영어 두 줄, 바로 아래 한글 두 줄).
- 아래: `영문 제목 · 한글 제목` → `Watch the full film — tap the related video ↓` → `전체 이야기는 아래 '관련 동영상'에서 ↓`.
- 처음 0.3초 페이드 인, 끝 0.7초 페이드 아웃. 소리는 원본 그대로 + loudnorm(-14 LUFS, TP -1.5).

### A-3. 글자 크기 (2026-11-21부터)
- 영어 첫 자막: 굵은 세리프 48px, 위에.
- 한글 첫 자막: 굵은 세리프 42px, 바로 아래(한글 굵은 글꼴은 같은 크기면 더 커 보여서 조금 작게).
- 아래 제목 줄 40px(영·한 한 줄), 안내 문구 영 30 / 한 28.
- 영어 문장은 `\n`으로 두 줄로 나눠 크기가 줄지 않게 한다(`fit()`이 980px를 넘으면 글자를 줄인다).
- 2026-11-20에 올린 예고 쇼츠 4편은 옛 크기(한글 62, 영어 32)로 만들어졌다.

### A-4. 만드는 순서
```bash
cd "Code Animation/_channel/tools"
export TEASER_SRC=/mnt/user-data/uploads/AI자동화애니메이션테스트   # 원본 가로 mp4 폴더
export TEASER_OUT=/home/claude/work/sc/out
# 1) CLIPS에 항목 추가: src, ss(시작초), t(길이), box=(크롭폭, 크롭높이, 위쪽 여백), x(크롭 x식), ko, en, title, title_en
# 2) 정지 화면으로 글자·크롭 확인(실제 크기로 본다)
python3 make_teaser_short.py keeper 6.0
# 3) 사용자 확인 뒤 전체
python3 make_teaser_short.py keeper
```
- 원본이 1920×1080이면 4:3 크롭은 `box=(1440,1080,0)`. 위아래 검은 띠가 있는 원본(허수아비 1920×1040)은 `box=(1386,1040,20)`.

## B. 종이 지식 쇼츠

> **2026-11-21부터 지식 쇼츠는 `trivia/`(알쓸신잡풍 자동 제작 엔진)로 12시간마다 한 편씩 만든다.** 사용법·검사 기준은 `trivia/README.md`, 주제 목록은 `trivia/topics.md`. 아래 B-2~B-3은 그 전에 손으로 만든 3편(haedal·simhae·hive) 방식이다.

### B-1. 컨셉
- 한 편 = 질문 하나. 첫 화면에 질문을 크게(예: "24절기는 음력일까?", "벌집은 왜 육각형일까?").
- 그림은 종이 오림·겹 종이: 크림색 종이, 그림자, 종이 결, 시차가 다른 여러 겹. 화면 글자는 한·영 병기.
- 흐름: 질문 → 직관적인 비교(원 vs 육각형, 에베레스트 vs 해구) → 확인된 숫자 하나 → 짧은 정리 → 허상공방 낙관·크레딧.
- 숫자는 출처로 확인한 것만 화면에 쓴다(코드 주석에 계산식·근거를 남긴다. 예: hive의 `GAP = 1 - π/(2√3)` = 9.3%).
- 관련 동영상은 분위기가 맞는 롱폼 단편으로 건다(해의 달력→허수아비의 겨울, 얼마나 깊을까→빛지기, 벌집→홀씨).

### B-2. 코드 구조
| 폴더 | 작품 | 비고 |
|---|---|---|
| `haedal/` | 해의 달력(약 60초) | `paper.py`(종이 층·질감·합성), `shapes.py`(오림 도형) — 다른 지식 쇼츠가 함께 씀. 가로·세로 둘 다(`HD_ORIENT=h|v`) |
| `simhae/` | 얼마나 깊을까(약 55초) | 세로 전용. 깊이(m) ↔ 화면 y 변환, 층마다 시차·물빛·초점 흐림 |
| `hive/` | 벌집은 왜 육각형일까(약 52초) | 세로 전용 |
| `jamo28/mg.py` | 움직임 함수 | 이징(expo, back, spring)·ramp·lerp. 지식 쇼츠가 이것만 가져다 씀 |
| `jeom/audio/` | 소리 | `instruments.py`(거문고·북 합성), `sketch.py`(리버브) |
| `_shared/seal_baimun3.npy` | 낙관 | 크레딧 |

- 각 작품: `scene.py`의 `frame(t)`/`final(t)`가 t의 순수 함수, `render.py out t0 t1`이 두 프로세스로 PNG를 만든다, `audio.py out.wav`가 numpy로 소리를 합성한다.
- 환경 변수: `HD_SCALE`(1 = 1080×1920 디자인 픽셀), `HD_ORIENT`(v/h), `MG_FPS`(기본 60, 지식 쇼츠는 scene의 FPS=30을 씀).
- 첫 실행 때 `haedal/cache/`에 종이 질감을 만든다(저장소에는 넣지 않음).

### B-2a. 화면 글자 크기 (2026-11-21부터, 새로 만드는 지식 쇼츠 전부)
- 한 문구를 영·한으로 함께 쓸 때 **영어를 위, 한글을 바로 아래**에 두고 크기를 맞춘다.
  - 영어 = 한글 + 4px 정도(한글 굵은 글꼴은 같은 크기면 더 커 보임). 예: 큰 질문 EN 76 / KO 72, 본문 EN 48 / KO 44.
  - 굵기도 맞춘다(한쪽만 굵게 하지 않는다). 강조색은 두 언어에 같이 준다.
- 영어가 길면 크기를 줄이지 말고 두 줄로 나눈다(세로 화면 폭 기준 한 줄 약 900px).
- 화면 안에서만 쓰는 고유 용어(층 이름 등)도 같은 규칙: `햇빛층 · SUNLIT`처럼 한 줄로 쓰면 두 글자 크기를 같게.
- **이미 올린 3편(해의 달력·얼마나 깊을까·벌집)은 옛 크기다**(한글 굵게 56~92, 영어 보통 30~34). `hive/scene.py` 등을 복사해 새 편을 만들 때 `slide_text` 호출의 크기를 위 규칙대로 다시 잡는다. 바꾼 뒤에는 정지 화면을 실제 크기(1080×1920)로 보고 글자가 넘치거나 겹치지 않는지 확인한다.

### B-3. 새 지식 쇼츠 만드는 순서
1. 주제 고르기: 그림 한 장으로 비교가 되는 질문, 숫자 하나가 놀라운 것. 숫자 출처 확인.
2. `hive/scene.py`를 복사해 새 폴더로. 시간표 상수(`T_B…T_END`)와 장면 함수만 바꾼다. 문구는 한·영 둘 다, 글자 크기는 B-2a대로(영어 위, 비슷한 크기).
3. 정지 화면 몇 장(`render.py` 짧은 구간) → 사용자 확인 → 짧은 움직임 → 확인.
4. 전체: `tools/render_paper_short.sh <폴더> <길이초> [작업폴더]` → `<폴더>_short_1080x1920.mp4`.
5. 사용자가 Studio에 올리면(초안) 아래 제목·설명 형식으로 채우고 관련 동영상을 건 뒤 예약.
