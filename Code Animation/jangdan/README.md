# 〈장단 JANGDAN〉 — 박자 동기 먹 모션그래픽 (첫 시험작)

32초(120 BPM, 16마디), 1080p 가능. 먹 방울(박마다) → 붓 획·살 → 흰 섬광 뒤 만화경(6→8→12→16겹) → 한 점 → 제목·낙관.
새 스킬(1·2·3·6번)과 공용 엔진 `_kit/vfx`를 한꺼번에 시험한 작품이다. 〈꺾기〉로 이어졌다.
- `nums.py` 숫자 파일(박자표·사건표·샷 표), `scene.py` 그림, `audio.py` 소리, `render.py` 렌더(`--stills` 가능).
- 540p 약 5분(만화경 5개 하위 프레임), 소리 포함 −14.1 LUFS, 트루 피크 −1.6.
- 약점: 만화경 색이 네온에 가까워 앞의 수묵과 결이 다르다. 모이는 빛점과 뒤의 먹점 높이가 어긋난다.
