# 〈점〉·〈파루〉 핵심 기술 시험 (2026-11-09)

목적: 두 후보작의 가장 큰 위험을 무음 짧은 영상으로 판정한다(cel-anime-direction 7장 6단계의 앞당긴 판).
영상(mp4)은 저장소 규칙대로 넣지 않았다. 아래 명령으로 다시 만든다. 대화에서 보낸 파일: `jeom_test_8s.mp4`, `paru_test_9s.mp4`.

검수 방식과 한계: 1080p 원본 프레임을 시점별 시트와 원본 크기 크롭 띠로 봤다. 영상을 실시간으로 재생해 보지는 못했으므로 리듬·연기의 최종 판정은 사용자가 영상으로 한다.

## 다시 만들기
```bash
pip install pycairo numpy scipy opencv-python-headless pillow scikit-image --break-system-packages
cd jeom && python3 test_jeom2.py jeom_test_8s.mp4      # 약 1분(2코어)
cd ../paru && python3 paru_test.py                    # 약 1.5분 → paru_test_9s.mp4
python3 paru_test.py still 3.9 6.6                    # 정지 샘플
```
모든 프레임은 t의 순수 함수이고 투스(12fps)로 그린다.

## 〈점〉 — 먹 번짐 (`jeom/`)
시험 내용(8초): 마르는 점 → 빗방울 → 젖은 곳으로 번져 감 → 튄 먹과 합쳐짐 → 비 그침, 테두리 진해짐 → 물 없이 세 번 모임(규칙 깨기).

### 시도와 결과
| 판 | 방식 | 결과 |
|---|---|---|
| v1 `ink.py` | 비선형 확산(물·먹·붙은 먹 3층) | 실패. 확산은 거리의 제곱만큼 느려서, 100px 움직이는 데 수천 스텝이 든다. 점이 거의 안 움직임 |
| v2 | 젖은 곳 안에서만 목표 쪽으로 흐름(이류) 추가 | 실패. 움직이긴 하지만 흐릿한 검은 원통이 미끄러짐 → CG 느낌. 번질수록 옅어진다는 규칙도 안 보임 |
| **v3 `test_jeom2.py`** | **번짐 사슬**: 물 앞전선 = 섬유 따라 걸리는 시간(측지 거리, scikit-image MCP) + 반지름 키. 먹은 미끄러지지 않고 새 물웅덩이로 피어나며, 떠난 자리는 옅은 얼룩으로 남음 | 채택. 섬유 결의 들쭉날쭉한 경계, 마를 때 진해지는 테두리, 겹친 얼룩의 농담이 먹처럼 읽힌다 |

### 이야기에 주는 영향 (스토리 문서 보완)
- 점은 몸이 통째로 움직이지 않는다. **번질 때마다 몸의 중심이 옮겨 가고 지나온 자리에 얼룩이 남는다.** 그래서 "지나온 길이 한 획 그림으로 남는" 결말(c)이 물리와 저절로 맞는다.
- 반대로 위험도 생긴다. 관객이 이 얼룩들을 **같은 한 존재**로 볼지가 핵심 판정 항목이다. 영상을 보고 판단해 주세요. 약하면 아래 보강안을 쓴다.
  - 가장 진한 곳(현재의 몸)에만 젖은 윤기와 가장자리 떨림을 준다.
  - 번지기 직전 0.3초 예비 동작(살짝 오그라듦)을 넣는다.

### 남은 문제
- 오른쪽 위 용의 마른 붓 획은 자리만 잡은 임시본이다. 가장자리가 너무 고르고 빗살 같다. 본 제작 때 따로 설계한다.
- 모인 점의 모양이 하트처럼 보인다. 모일 때 둥글게 다듬는 항이 필요하다.
- 밤 색보정(`still_night_4.6.png`)에서는 옅은 얼룩의 대비가 낮다. 밤 장면은 번개·등잔 같은 빛으로 대비를 확보해야 한다.
- 비용: 프레임당 약 0.5초(1080p). 2분 본편도 2코어로 30분 안쪽 예상.

## 〈파루〉 — 자격루 단면도 (`paru/`)
시험 내용(9초): 물이 차오름 → 거북 부력체의 살대가 걸쇠를 밂 → 보통 구슬이 홈을 굴러(틈 위를 넘어감) 지렛대를 침 → 큰 구슬 → 연결대 → 인형이 팔을 들었다(예비) 징을 침 → 주인공(작은 구슬)이 헐거운 구멍에서 덜컥거리다 굴러 나와 틈 건너편 모서리에 걸림 → 세 번 흔들림 + 빈 홀드 → 뒤로 넘어가 떨어짐.

### 결과
- 의궤 도설풍(손그림 먹선 + 1~2px 밀린 담채 + 단면 빗금 + 한지)이 첫 시도부터 읽힌다. 3D·벡터 느낌이 없다.
- 구슬 크기 차이(반지름 16 / 10.5 / 30)가 와이드에서도 보인다.
- 고친 것 두 가지:
  - 작은 구슬이 틈 한가운데 떠 있었다 → 건너편 모서리를 받침점으로 걸쳐 흔들리게 바꿈(`paru_ball2_strip.png`).
  - 방망이가 징 아래 테두리만 스쳤다 → 타격 각도를 올림(`strike_strip.png`).

### 남은 문제
- 화면이 비어 보인다. 파수호(물 보내는 항아리)들, 보루각 기둥·들보, 다른 구슬 줄을 채워야 "거대한 장치 속 작은 구슬"이 된다. 단면도 한 장을 먼저 설계하고 모든 컷을 그 위에 배치한다.
- 빗금 간격이 기계적으로 고르다.
- 인형 어깨가 몸통 밖에 붙어 있다(나무 인형 설정이라 허용 범위지만 다듬을 것).
- 징 흔들림이 약하다. 소리가 붙으면 다시 본다.
- 비용: 프레임당 약 0.9초(1080p).
- 내부 구조와 명칭은 고증 미확정. 화면 표기는 사료로 확인한 `受水壺`만 넣었다.
