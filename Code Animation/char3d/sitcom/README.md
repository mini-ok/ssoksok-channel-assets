# 몸속 주식회사 — 오늘의 판정 · 3D 파일럿(담석 편, 한국어판만)

〈심장의 휴가〉 3D 세트·캐릭터(뇌·장·간·심장)를 그대로 쓴 시트콤 파일럿. 애니매틱(three.js) 방식으로 서버에서 렌더(960×540 → 1920×1080 확대).
영상(mp4)·프레임·음성은 저장소에 넣지 않는다.

| 파일 | 하는 일 |
|---|---|
| `../sitcom_gb.html` | 컷 재생 페이지(film.html과 같고 컷·소품만 다름, `PAGE=sitcom_gb.html node render_film.mjs …`) |
| `cuts.js` | 43컷 정의 + 2D 합성·효과음 시간표(`TL`) + 컷마다 소품 상태 리셋 |
| `kit.js` | 연기 도구: 대사 입 움직임(`talk`), 자동 깜빡임, 말할 때 손짓(`act`), 걷기 |
| `props.js` | 새 소품: 관제실 큰 CCTV 모니터(2D 그림 모드들), 경보등, 기송관·캡슐, 내기 현황판; 간 공장 담즙 탱크 명패·압력계·출구 관·밸브·담석·그릇 더미; 장 연구소 기름진 상자·레버 판·방귀 구름 |
| `lines.js` | 대사별 입 벌림 단계(24fps, 음성 크기 → 0/0.35/0.7/1) — 녹음에서 자동 생성 |
| `gb_sound.py` | 대사 + 합성 효과음 + 채널 bgm(대사 구간 덕킹) |
| `gb_post.py` | 확대 + 컷별 후처리(되감기·인터뷰 흐림·화상 연결·어둡게) + 칩·자막·요약 카드 + 소리 합본 |
| `Jua-Regular.ttf` | 채널 글꼴(OFL). Jua에 없는 기호(·…→①)는 Noto Sans CJK로 섞어 그림 |

## 검수에서 배운 것
- Gemini-TTS는 연기 지시(act)를 주면 군말·웃음·지시문 낭독·같은 문장 반복이 섞일 때가 있다 → 말 속도(음절/유성 구간 초)로 이상 조각을 고르고, faster-whisper로 받아 적어 대본과 비교해 다시 녹음, 말 끝 뒤 꼬리는 잘라 낸다.
- 관제실 책상은 원점에서 뻗은 부채꼴 덩어리라 z<0 쪽에 서면 몸이 파묻힌다(z ≥ 0.5에 세움).
- 장은 오른손 플라스크가 옆 캐릭터·레버 판과 자주 겹쳐 이번 편은 숨김. 4막 설거지 장면은 간 깔때기·물병 선반을 치움.
- 매 프레임 충돌 검사(cuts 모드의 `.collide.txt`)에서 걸린 컷만 고쳐 다시 렌더: 최종 관통 0건.
