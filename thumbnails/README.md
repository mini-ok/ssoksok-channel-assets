# 쇼츠 썸네일 모음 (사용자가 Studio에서 직접 올린다)

쇼츠 맞춤 썸네일은 API 호출 비용(호출당 50유닛) 대비 노출이 불확실해 자동 설정하지 않는다(2026-10-28).
대신 제작 때마다 쇼츠 썸네일을 이 폴더에 모은다. 롱폼 썸네일은 API로 설정하므로 모으지 않는다.

- `shorts/ko/`, `shorts/en/` — 파일명 `YYYY-MM-DD_<주제>_<video id>.jpg`
- 새 파일은 제작 실행이 push하고, 실패하면 SendUserFile로만 전달된다.
- `backfill_*` 파일은 유튜브 서버에 저장돼 있던 복사본(가로 칸에 맞춰 줄어든 저해상도)이라 원본보다 화질이 낮다.
