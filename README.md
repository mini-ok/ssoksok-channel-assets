# 쏙쏙 건강백과 · Tiny Body Co. 채널 자료

두 유튜브 채널(쏙쏙 건강백과 @ssoksok-health, Tiny Body Co. @tinybodyco)의 제작 자료 백업 저장소.

| 폴더 | 내용 |
|---|---|
| `bgm/` | 배경음악 (수노 제작, 가사 없는 연주곡) |
| `thumbnails/` | 롱폼 썸네일 (한/영) |
| `style-tests/` | 화풍 시안: 캐릭터 스타일, 세 가지 잉크, 종이+청사진, 종이 스토리(채택 방향) 스틸·모션 테스트 |
| `docs/` | 업로드 자료, 유튜브 API 설정 가이드, OAuth 브랜딩 페이지 문구 |
| `web/` | goxon.kr 앱 소개·개인정보·약관 페이지 |

비밀 값(클라이언트 보안 비밀, 리프레시 토큰, API 키)은 이 저장소에 넣지 않는다. 환경 설정에만 둔다.

## 배경음악

| 파일 | 길이 | 통합 음량 | 용도(예정) |
|---|---|---|---|
| `bgm/main_tema.mp3` | 89.6초 | -15.8 LUFS | 기본 설명 장면 |
| `bgm/nimble_motifs.mp3` | 88.8초 | -16.2 LUFS | 질문·후크, 경쾌한 전환 |
| `bgm/buant_pop_groove.mp3` | 91.2초 | -15.3 LUFS | 활기찬 장면, 엔딩·구독 멘트 |

영상에서는 내레이션보다 충분히 작게(약 -30 LUFS 전후) 깔고, 말하는 구간은 더 줄인다(덕킹). 수익 창출 채널에서 쓰려면 수노 유료 플랜에서 만든 곡이어야 한다.
