# 쏙쏙 건강요리 · 핵심 설정과 고정 구조

## 핵심 설정 (사용자 재확인, 2026-10-29)

**장기 요리사는 자기 장기에 도움 되는 요리를 한다.** 요리가 어떤 부위에 어떤 이유로 도움이 되는지가 시리즈의 주제다. 캐릭터는 장식이 아니다. "뇌 팀장이 대신 해도 달라질 것이 없는 영상"이면 기획을 다시 한다.

병아리콩 2편처럼 **요리가 끝난 뒤 여성 나레이션이 건강상 이유를 근거와 함께 설명하는 장면이 필수**다. 셰프의 짧은 훅이나 출처 이름만으로 이 장면을 대신할 수 없다.

## 기획 순서

1. 건강 포인트를 정한다. 예: 심장·혈관 건강과 LDL 콜레스테롤 관리.
2. 공신력 있는 기관·원 연구에서 근거, 적용 조건, 한계를 확인한다.
3. 그 근거를 실제로 보여 주는 재료·분량·조리법을 정한다.
4. 해당 장기 쉐프를 배정하고 "왜 내가 이 요리를 하는가"를 한 문장으로 쓴다.
5. 메뉴 이력과 겹침을 확인한다. 같은 주재료와 비슷한 요리 스타일은 최소 10편 간격. 부재료·양념은 재사용 가능.
   가능하면 장기별로 번갈아 등장시킨다(사용자 지시 2026-10-29). 장기 순환을 위해 근거가 약한 요리를 억지로 연결하지 않는다. 이번 3편은 심장 쉐프로 확정했고, 다음 편부터 다른 장기를 우선 검토한다.
6. 기획서와 대본을 완성한 뒤 음성 합성·전체 렌더로 진행한다.

"영양가 있다", "단백질이 있다", "채소와 함께 먹는다"만으로 특정 장기와 연결했다고 보지 않는다. 특정 식재료의 효과를 레시피 전체의 입증된 효과처럼 말하지 않는다. 대체 섭취가 근거이면 무엇 대신 먹는지를 설명해야 한다. 한 번 먹어서 치료·해독·수치 개선이 보장되는 것처럼 표현하지 않는다.

## 모든 편의 고정 흐름

**장기 쉐프 등장·선정 이유 → 재료 → 조리 → 여성 나레이션의 건강 근거 설명 + 큰 출처 표기 → 캐릭터 유머 → 전체 레시피·엔딩**

- 쉐프는 밝고 신나게 요리하며 조리 대사를 한다. 여성 해설은 재료와 건강 근거를 설명한다.
- 조리 후 설명은 해당 음식의 성분/조리 선택 → 작용 또는 식습관 → 해당 장기에 도움이 되는 이유까지 연결한다.
- 근거의 핵심 조건을 나레이션과 화면에 모두 반영한다. 예: "포화지방을 불포화지방으로 바꿔 먹을 때".
- 출처 기관과 자료 주제를 다른 본문 자막과 비슷한 크기로 표시한다. 작은 각주만 넣지 않는다. 직접 링크·확인일·지원 주장·한계는 기획서에 기록한다.
- 레시피 카드는 제목·분량·재료량·전체 조리법을 넣고 충분히 고정해 바로 캡처할 수 있게 한다.
- 우상단: `쏙쏙 건강요리`. 상단: `오늘의 요리사 : ○○ 쉐프`.
- 엔딩 대사: `구독은 사원증 발급! 좋아요는 보너스!`
- 기본 음성 속도는 원음 기준 1.3배. 말투는 명랑하고 톡톡 튀게. 기존 종이 질감과 큰 자막 유지.
- 조리 동작과 효과음을 맞추고 전환을 충분히 부드럽게 한다. 요청으로 뺀 의료 안내 하단 자막을 다시 넣지 않는다.

## 제작 전 필수 점검

- [ ] 장기 / 건강 포인트 / 주재료 / 적용 근거가 기획서에 연결되어 있는가?
- [ ] 왜 이 장기 쉐프여야 하는가를 말할 수 있는가?
- [ ] 전세계에서 쉽게 구할 재료와 간단한 조리인가?
- [ ] 메뉴 이력의 주재료·스타일 반복 기준을 지켰는가?
- [ ] 조리 후에 여성 건강 근거 나레이션이 있는가?
- [ ] 나레이션과 출처 화면이 같은 주장을 뒷받침하며 적용 조건을 지켰는가?

## 최종 영상 필수 검수

원본 크기의 자막·출처·캐릭터·조리 동작 확인, 최종 MP4 전체 디코딩, 음량·피크 확인, 음악과 효과음을 포함한 최종 대사 받아쓰기, 설명 장면의 순서 및 실제 출력 확인, 엔딩 레시피 정지 확인 후 완료 보고한다. 차단되거나 미검증인 범위는 명확히 밝힌다.

3편 버섯 달걀볶음 초안은 일반 영양 설명만 있어 장기 선정 이유가 빠졌으므로 최종본으로 사용하지 않는다. 최종 3편은 심장 쉐프의 사과 땅콩버터 토스트이며, 핵심은 버터 대신 불포화지방이 많은 땅콩버터를 쓰는 대체 선택이다.
