# 손그림 셀 질감 노하우 (〈허수아비의 겨울〉 제작 중 검증)

## 벡터처럼 보이는 원인 → 해결
| 원인 | 해결 (cel.py v2) | 결과 |
|---|---|---|
| 윤곽이 수학적으로 완벽한 곡선 | 윤곽을 2.5px 간격으로 다시 찍고, 둘레를 따라 **아주 낮은 주파수(약 140px 주기)** 흔들림 1px 안팎. 중간 주파수(25~40px)는 거의 0 | 중간 주파수를 키우면 '젤리처럼 울렁이는 필터'가 됨. 큰 형태만 살짝 어긋나야 손그림 |
| 외곽선 굵기가 일정 | 펜 압력: 빛 반대쪽 0.45→1.4배, 둘레 따라 ±18% 압력 변화 | 무게감, 그림자 쪽이 단단해 보임 |
| 닫힌 도형이 한 번에 그어짐 | 외곽선을 **2~4개의 획으로 나눠** 시작·끝을 가늘게(테이퍼) 하고 살짝 겹치게 | 사람이 여러 번에 나눠 그은 선의 끊김과 겹침 |
| 그림자가 윤곽을 평행이동한 모양 | 그림자 폭을 둘레 따라 0.55~1.45배로 바꿈(디자인된 그림자) | 기계적 오프셋 느낌 제거 |
| 선이 매 프레임 똑같거나 매 프레임 바뀜 | 형태 흔들림 시드는 고정, 미세 떨림 시드만 투스(12fps)마다 교체 | 라인 보일. 모델은 유지 |
| 셀 레이어가 배경과 너무 붙음 | `cel_finish`: 0.5px 광학적 무름, 저주파 물감 얼룩 ±1.8%, 배경과 미세한 색 차(약간 차갑게) | 촬영대 위 셀 질감 |
| 배경 논이 단조로움 | 논배미마다 색조 다르게(붉은 익음, 연노랑, 녹금), 배미 안 붓질이 이랑 방향을 따름, 두렁 폭 변화와 풀 술 | 패치워크와 계절감 |
| 소품 디자인이 단순(매) | 실루엣의 '종 특징'을 넣음: 손가락처럼 벌어진 첫째 날개깃, 줄무늬 꼬리, 눈선, 갈고리 부리 | 한눈에 맹금류로 읽힘 |

## 아직 남은 격차 (다음 단계 후보)
- 배경이 '붓으로 칠한 포스터컬러'보다 일러스트에 가까움 → 형태를 따라가는 방향성 붓질 엔진(면의 방향장으로 스트로크 배치), 마른 붓 가장자리
- 외곽선이 모든 부품에 같은 굵기 → 바깥 실루엣만 굵게(합친 실루엣을 따로 한 번 더 긋기)
- 정지 이미지만 검수함 → 투스 타이밍과 라인 보일은 짧은 구간 영상으로 확인 필요
- 평면적 공간감 → 다음 작품에서 three.js(캐릭터 3D 배치) + 이 셀 렌더를 결합

## 포스터컬러 배경 엔진 (painter.py) — 검증
- 방식: 기존 배경(하늘+구름+땅)을 한 장으로 합친 밑그림 → 구조 텐서 방향장(형태의 결) + 지역별 힌트(수평) → 굵은 붓부터 가는 붓까지 4단계(반지름 26/13/6/3px) 곡선 스트로크. 스트로크는 밑그림 색과 0.16 이상 달라지면 멈춤(경계 보존).
- 1차 시도(반지름 18/10/5/2.5, 잔붓 기준 낮음): 화면 전체가 고른 잔붓 → **인상파 유화/모자이크**처럼 보임. 실패.
- 해결: 평평한 곳은 큰 붓·긴 획(하늘 2.6배, 들판 2.0배 길이), 잔붓은 오차가 큰 디테일 부위만(기준 0.06/0.09/0.13), 하늘은 붓결 줄무늬를 약하게(0.18).
- **그린 디테일 되살리기**: 밑그림의 고주파 성분(원본 − 2.2px 블러)을 0.7배 다시 더함 → 두렁·길·잎 같은 선 디테일이 붓질 위에 남아 '물감 위에 다시 그린' 애니 배경 느낌.
- 하늘 소용돌이: 구름 주변 방향장이 원을 그림 → 하늘에서는 방향장 가중치 0.25로 낮춰 수평 힌트 우선.
- 비용: 2400×1300 한 장 약 35초 → 계절별 PNG 디스크 캐시.
- 주의: 배경에 속하는 큰 형태(앞쪽 둔덕, 눈더미)를 캐릭터 층에 셀로 그리면 그 부분만 평평해 보임 → 배경 밑그림에 넣고 함께 칠할 것.

## 움직임 시험 (motion.py) — 검증
- 키 포즈 목록 + 계단식 중간 그림 1~2장, 시간은 투스로 양자화. 돌풍 0.12초 상승/0.2초 하강, 팔은 0.25초 안에 올라가고 내려올 때 −0.45로 한 번 넘쳤다가 −0.2로 안착(오버슈트) → 짚 인형의 탄력.
- 착지는 찌그러짐 0.78 → 늘어남 1.12 → 1.0 (2프레임씩), 착지 후 깃털 부풀리기 홀드.
- 바람이 멈춘 0.8초의 '빈 홀드'가 코미디 타이밍을 만든다(콩이가 화면 밖에 있는 동안 짚이만 정지).
- 렌더: 1080p 프레임당 약 0.8초(2코어 병렬 시 10.5초 영상 83초).

## 본 제작 (film.py, 22컷 125초) — 검증
### 배경 계절 11종
- 같은 장소를 시간·계절로 다시 칠하기: 하늘 그라디언트 3~4스톱, 구름 사양(위치·폭·높이)을 계절별 dict로, 들판 종류(벼/그루터기/눈/해빙/무논)를 분기. 그루터기 밭은 소실점으로 모이는 줄 + 짚단(눈모자 여부 caps 0~1).
- **실패 → 해결**: 노을 구름을 납작하게(높이 70, 폭 800) 하면 벽돌처럼 쌓여 보임 → 높이 100~130, 폭 300~600. 해빙 눈조각을 고른 타원으로 흩으면 물방울무늬 → 눈은 두렁 바로 아래 그늘에 띠로 남기고(실제 눈 녹는 방식), 웅덩이는 불규칙 다각형 + 하늘 반사 하이라이트 한 줄.
- 해/달이 구름 사양에 가려지지 않는지 컷의 카메라로 확인(노을의 해가 가려져 있었음).
- 앞쪽 둔덕: 채도를 낮추고(0.44,0.58,0.30), 아래로 갈수록 어둡게 5단 띠, 둔덕 꼭대기 실루엣에 풀 술 700개, 들꽃 220개 → 평면 녹색 덩어리가 '언덕'이 됨.
### 연출
- **바람 규칙의 클라이맥스**: 실이 끊기는 순간 바람·소리·눈발이 모두 멈추고(눈 입자 시간을 그 순간에 고정), 그 정적 속에서만 짚이가 움직인다(허리를 단계적으로 −8/−16/−24°, 홀드 + 나무 갈라지는 소리 3번). 규칙을 깨는 장면을 '세상이 멈춘 시간'으로 만들면 설명 없이 읽힌다.
- 바람 방향은 이야기 동선이 정한다: 콩이가 왼쪽 소매로 날려가야 하므로 눈보라는 오른쪽→왼쪽. 눈더미는 바람이 지나간 쪽(왼쪽)으로 긴 꼬리 + 기둥 쪽 가파른 면(실제 바람그늘 눈더미 모양).
- 소매가 땅까지 닿지 않는 문제는 포즈를 억지로 늘리지 말고 지형(눈더미)으로 해결. 눈더미를 캐릭터 층에 두면 해빙 타임랩스에서 높이만 줄여 '녹는' 애니메이션이 공짜로 생김.
- 허리 굽힘 + 머리 기울기 + 모자 기울기가 합쳐 60°를 넘으면 '다이빙/댑' 포즈로 보임 → 굽힘 −24°, 머리 = 굽힘×0.5, 모자는 반대로 +4°. 굽힘이 반대쪽 팔을 들어 올리므로 그 팔은 flap −1.0으로 내려줌.
- 쓰러진 허수아비: 팔이 몸과 직각이라 땅을 찌름 → arm_len 0.5, 몸 아래 가장자리만 풀 술로 덮기(얼굴까지 덮으면 지저분).
- **배경에 있는 지형(둔덕) 위에 캐릭터를 놓는 컷은 배경 카메라와 캐릭터 카메라를 같게** 해야 발이 땅에 붙는다(다르면 모자가 물 위에 뜸).
- 하모니 프레임: 완성 합성 프레임을 2400×1300으로 키워 painter(반지름 14/7/3.5/1.8, 디테일 0.55)로 다시 칠해 캐시 → 카메라만 천천히 당김. 같은 장면이 '한 장의 그림'으로 바뀌는 순간.
- 제목: 밝은 봄 하늘 위에서는 크림색 글씨가 안 읽힘 → 남색 잉크 글씨 + 크림색 테두리, 나무를 피해 오른쪽 위.
### 사운드
- 하나의 5음 음계 모티프(E G A C A G E D)를 계절마다 다른 화성으로: 가을 C장조, 겨울 A단조, 봄 D장조. 오카리나 = 사인 + 2·3배음 약간 + 숨소리(대역 잡음) + 지연 비브라토.
- 정적 구간은 리버브 꼬리까지 0으로 자르고, 레벨러가 정적을 끌어올리지 않게 마스크, 정적 속 소리(착지·나무 갈라짐·소매 스침)는 레벨링 뒤에 고정 레벨로 더함. 갈라짐은 주변 장면보다 RMS 약 10dB 낮게 — 크게 하면 놀람, 작게 하면 정적이 더 깊어짐.
### 비용
- 프레임당 약 1.2초(2코어 병렬 시 125초 영상 약 30~40분). 배경 1장 그리기 약 35초(캐시).
