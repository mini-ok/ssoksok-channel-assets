이 앱이 하는 일

  • 채널 소유자(고엑스온)가 승인한 본인 소유 YouTube 채널 두 곳에 영상을 업로드합니다.
  • 영상의 제목, 설명, 태그, 썸네일, 재생목록, 첫 댓글을 함께 설정합니다.
  • YouTube Data API v3를 사용하며, 채널 소유자 본인의 계정으로만 동작합니다.

누가 쓰나요

About this app

A personal tool used by GOXON to upload videos to its own health-information animation channels, 쏙쏙 건강백과 and Tiny Body Co.

  • Uploads videos to the two YouTube channels owned by the app's owner, with the owner's authorization.
  • Also sets each video's title, description, tags, thumbnail, playlist and first comment.
  • Uses the YouTube Data API v3 and works only with the owner's own account.

Who uses it

A single channel owner. It is a private tool, not a service offered to the public. It does not sign in to anyone else's account or access anyone else's data.
